# 基于 IF 神经元的脉冲神经网络硬件实现与能耗-准确率权衡分析

## 结题报告

---

## 摘要

本课题基于 Cadence 180nm 工艺，设计并验证了一套用于脉冲神经网络（SNN）的硬件单元，包括乘累加器（MAC）单元和 Integrate-and-Fire（IF）神经元。在 MNIST 手写数字识别任务上，通过 ANN-to-SNN 转换与 (T, Vth) 参数扫描，量化分析了 SNN 相比传统 ANN 的能耗-准确率权衡关系。

核心结果表明：采用 data_based 归一化方法，在 T=50、Vth=0.5 的配置下，SNN 的准确率仅比 ANN 下降 0.2%（96.8% vs 97.0%），但一次推理能耗仅为 ANN 串行单 MAC 基线的 1.32%，节能百分比达到 98.68%，延迟从 119.1 ms 降至 25.0 µs。本课题还完成了面积-延迟-功耗（PPA）综合对比，并基于实验数据提出了严格的衍生结论与后续优化方向。

**关键词**：脉冲神经网络；Integrate-and-Fire 神经元；能耗-准确率权衡；Cadence；MNIST

---

## 第一章 绪论

### 1.1 研究背景

随着人工智能应用的普及，神经网络推理的能耗与延迟问题日益突出。传统人工神经网络（ANN）依赖大量乘累加运算，在边缘设备上部署时面临功耗和实时性的双重挑战。脉冲神经网络（Spiking Neural Network, SNN）模拟生物神经元的事件驱动特性，仅在输入达到阈值时产生脉冲，具有天然的稀疏性和低功耗潜力，成为神经形态计算领域的研究热点。

### 1.2 研究意义

SNN 的节能效果并非无代价。脉冲离散化、时间编码等因素可能导致信息损失，从而降低任务准确率。因此，在实际部署中需要量化分析：**SNN 每节省多少功耗，会损失多少准确率**。这一权衡关系是 SNN 能否替代或补充 ANN 的关键判据。

### 1.3 研究内容与方法

本课题的主要工作包括：

1. **硬件单元设计**：在 Cadence 180nm 工艺下设计 MAC 单元和 IF 神经元，并完成电路功能验证。
2. **功耗与延迟测量**：通过 Virtuoso ADE 仿真测量 MAC 和 IF 单元的动态功耗、静态功耗及关键路径延迟。
3. **SNN 转换与扫描**：在 MNIST 784→300→10 网络上进行 ANN-to-SNN 转换，扫描不同时间步长 T 和阈值 Vth 的配置。
4. **能耗-准确率权衡分析**：基于实测功耗数据填充 trade-off 数据，绘制 Pareto 前沿和核心曲线。
5. **PPA 综合对比**：从面积、延迟、功耗三个维度对比 SNN 与 ANN 基线。

## 第二章 硬件电路设计与实现

### 2.1 整体设计思路

本课题的硬件部分包括两类核心单元：

- **MAC 单元**：用于 ANN 基线的乘累加运算，包含 4×4 乘法器阵列、4-bit 超前进位加法器（CLA4）和 REG4 寄存器。
- **IF 神经元**：用于 SNN 的脉冲积分与发放，包含 MUX4 积分器、ADD4 加法器、REG4 寄存器、CMP_GE 比较器和 SYNC_RESET 同步复位电路。

### 2.2 D 触发器设计

D 触发器（DFF）是 MAC 和 IF 神经元中寄存器的基本单元。本项目采用下降沿触发方式，具有清零（CLR）功能。在初始版本中，DFF 存在 Q=~D 的输出反相问题，通过在 Virtuoso schematic 视图中调整传输门输入连接，将锁存器输入从反相节点改接到同相节点，最终使 Q=D。

### 2.3 MAC 单元设计

MAC 单元实现逐周期累加功能：每个时钟下降沿，将 A×B 的低 4 位结果累加到寄存器 ACC 中。设计要点：

- 4×4 乘法器输出 8-bit 乘积，低 4 位接入 CLA4。
- CLA4 完成当前乘积与 ACC 的加法。
- REG4 在 CLK 下降沿锁存新的 ACC 值。
- CLR 高电平时复位 ACC 为 0。

### 2.4 IF 神经元设计

IF 神经元在脉冲到来时积分权重，膜电位 V 达到阈值 Vth 时发放脉冲并复位。设计要点：

- **MUX4 积分器**：当 SPIKE_IN=1 时选择权重 W，SPIKE_IN=0 时选择 0。
- **ADD4**：将选中的权重加到当前膜电位 V。
- **REG4**：在 CLK 下降沿锁存新的膜电位。
- **CMP_GE**：比较膜电位 V 与阈值 Vth，当 V≥Vth 时产生 SPIKE_OUT。
- **SYNC_RESET**：在 SPIKE_OUT 产生后的下一个时钟周期将膜电位清零。

初始版本中 MUX4 选择逻辑反相，导致 SPIKE=0 时错误地选择权重。通过在 schematic 视图中交换 MUX4 的输入组（D00-D03 接 gnd!，D10-D13 接 W0-W3）修复了该问题。

## 第四章 功耗与延迟测量

### 4.1 测量方法

动态功耗通过在 Testbench 中添加独立 vdc 电源（1.8V）并测量 `1.8 * average(IT("/VDD/PLUS"))` 获得。静态功耗通过 DC 分析测量 `IDC("/VDD/PLUS")` 并乘以 1.8V 获得。关键路径延迟通过 ADE Calculator 的 `delay()` 或 `cross()` 函数测量。

### 4.2 测量结果

| 指标 | MAC 单元 | IF 神经元 | 备注 |
|---|---|---|---|
| 动态功耗 | 4.876 µW | 2.627 µW | 2MHz，1.8V |
| 静态功耗 | 0.005827 µW | 0.005951 µW | 输入全 1，CLK=0，CLR=0 |
| 未折算有效功耗 | 4.870 µW | 2.621 µW | 动态 - 静态 |
| 折算后有效功耗 | 4.870 µW | 9.611 µW | 未折算 × 3.67 |
| 关键路径延迟 | ~50 ns | ~149 ns | 2MHz 时钟下满足时序 |
| 晶体管数量 | 942 | 514 | 基于最终 CDL 自动统计 |
| 单次操作能量 | 2.435 pJ | 4.805 pJ | @ 2MHz |

### 4.3 IF 功耗折算说明

IF 神经元 Testbench 在 5.5 µs 仿真窗口内共 11 个时钟周期，但只有 3 个有效脉冲事件。因此测得的平均功耗需要按 `11 / 3 ≈ 3.67` 放大，才能得到“每次脉冲事件”的等效功耗：

```
P_IF_single = (2.627 - 0.005951) × 3.67 ≈ 9.611 µW
```

## 第五章 SNN-ANN 能耗-准确率权衡分析

### 5.1 网络结构与转换方法

采用 MNIST 手写数字识别网络，结构为 784 → 300 → 10：

- 输入层：784 个像素
- 隐藏层：300 个神经元
- 输出层：10 个神经元

使用 ANN-to-SNN 转换方法：先训练一个带 ReLU 激活的 ANN，然后将 ReLU 替换为 IF 神经元，权重分别按 data_based 和 max_norm 两种方法归一化。

### 5.2 ANN 参考能耗

总 MAC 次数：

```text
784 × 300 + 300 × 10 = 238,200
```

ANN 一次推理能耗（单 MAC 串行基线）：

```text
E_ANN = 4.870 µW × 238,200 = 1,160.075 mW·cycle
```

换算为能量：

```text
E_ANN = 1,160.075 mW × (1 / 2 MHz) = 580,037.5 pJ ≈ 580,000 pJ
```

ANN 准确率：97.0%。

## 第七章 衍生结论与讨论

### 7.1 数据直接支持的结论

1. **归一化方法决定 trade-off 形态**：在本项目 MNIST 网络上，data_based 全面优于 max_norm。
2. **T=50 是 data_based 拐点**：T<50 准确率随 T 增加而提升，T>50 准确率反而下降。
3. **IF 单次功耗约为 MAC 的 2 倍**：SNN 节能只能来自操作次数少（约 150 倍），而非单次操作更省。
4. **IF 延迟是时钟瓶颈**：149 ns 延迟迫使时钟降到 2MHz。
5. **同面积 ANN 仍无法追上 SNN 延迟**：310 MAC 全并行 ANN 延迟仍是 SNN T=50 的 15 倍以上。

### 7.2 数据强烈暗示的结论

1. **“零准确率损失”的 SNN 可能存在，但节能空间会缩小**：max_norm T=100, Vth=5.0 已实现 97.0% 准确率，但节能仅 94.02%。
2. **Vth 最优区间可能很窄**：T=50 时 Vth=0.5（96.8%）略优于 Vth=1.5（96.4%）。
3. **4-bit 膜电位可能是瓶颈**：T>50 准确率下降，可能与膜电位饱和有关。
4. **继续增大 T 的收益有限**：T=50 后准确率不再提升，信息容量或已饱和。

### 7.3 需谨慎对待的推测

引入 LIF 泄漏、SNN-aware 训练、混合 ANN-SNN 架构、temporal/TTFS 编码、DVS 事件相机、降低电源电压等，均属于神经形态计算领域的通用建议，需要后续实验验证，不能从本项目数据中直接推导。

### 7.4 不能过度推断的结论

1. SNN 并非在所有场景下都比 ANN 节能。
2. data_based 并非在所有数据集上都优于 max_norm。
3. T=50 未必是绝对最优（T=60、70 等中间值未扫描）。
4. 增加膜电位位宽一定能提升准确率，需要实测验证。

## 第八章 结论与展望

### 8.1 主要结论

本课题完成了 IF 神经元和 MAC 单元的电路设计、功能验证、功耗延迟测量，并在 MNIST 任务上系统分析了 SNN 与 ANN 的能耗-准确率权衡。核心结论如下：

1. **硬件电路功能正确**：修复了 DFF 输出反相和 MUX4 选择逻辑问题，MAC 和 IF 神经元均通过功能验证。
2. **data_based 归一化效果显著**：在 T=50、Vth=0.5 时，SNN 准确率 96.8%，能耗仅为 ANN 的 1.32%，节能 98.68%。
3. **SNN 节能来自事件稀疏性**：IF 单次事件功耗虽为 MAC 的 2 倍，但 SNN 操作数少约 150 倍，系统级能耗低两个数量级。
4. **存在明显拐点**：T=50、Vth=0.5 是性价比最高点，继续降低 T 的边际收益迅速递减。
5. **SNN 在延迟上具有显著优势**：即使 ANN 使用与 SNN 相同的晶体管预算，其延迟仍是 SNN 的 15 倍以上。

### 8.2 后续展望

1. 扫描 T=60~150、Vth=0.3~1.0 的 data_based 配置，寻找“零准确率损失 + 高节能”配置。
2. 将膜电位位宽从 4-bit 提升到 6-bit 或 8-bit，验证截断误差对准确率的影响。
3. 优化 IF 神经元关键路径延迟，尝试将时钟频率提升到 5~10MHz。
4. 实现 LIF 泄漏项或 SNN-aware 训练，进一步缩小 SNN 与 ANN 的准确率差距。
