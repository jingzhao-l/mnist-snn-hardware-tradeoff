## 第二章 软件实施：ANN-to-SNN转换

### 2.1 任务概述

将训练好的ANN权重转换为SNN格式，用IF脉冲神经元替代ReLU/sigmoid激活函数，在MNIST上验证SNN的识别准确率（目标≥85%），统计脉冲稀疏性。

### 2.2 ANN-to-SNN转换算法

### 2.2.1 核心思想

不从头训练SNN，而是直接复用已训练好的ANN浮点权重。ANN的激活值（ReLU输出）替换为IF神经元的脉冲发放率（Firing Rate）。原理是：输入图片编码为脉冲序列后，IF神经元的膜电位累积速度与ANN的激活值成正比。

### 2.2.2 转换步骤

```
Step 1: 加载ANN权重
  W1, b1, W2, b2 ← 从ann_mnist_weights.npz加载

Step 2: 权重归一化
  - 原因：IF神经元的脉冲发放率与输入权重的幅值相关
  - 方法：找到每层权重的最大绝对值max_W，W_norm = W / max_W
  - 阈值theta_IF通常设为1.0

Step 3: 泊松编码（将MNIST图片转为脉冲序列）
  对于每个像素值pixel ∈ [0, 1]（已经除以255）：
    在每个时间步t，生成一个随机数rand ∈ [0, 1]
    如果rand < pixel → 在时间步t发放一个脉冲（spike = 1）
    否则 → 不发放（spike = 0）
  结果：一张28×28=784像素的图片，被编码为784个泊松脉冲序列
  每个序列长度 = num_timesteps

Step 4: IF神经元前向传播（替代ANN的ReLU）
  第i个神经元的膜电位 V_i 初始为0
  在每个时间步t：
    输入脉冲 × 归一化权重 → 累加到V_i
    如果 V_i > 阈值theta → 发放一个脉冲，V_i 重置为0
    否则不发放
  N个时间步后，统计每个神经元的脉冲发放总数
  输出层10个神经元中，发放次数最多的 = 识别结果

Step 5: 准确率评估
  遍历MNIST测试集全部10000张图片
  对比预测值与真实标签
```

### 2.2.3 关键参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| num_timesteps | 50 | 每张图片仿真的时间步数（越多越准但越慢） |
| threshold | 1.0 | IF神经元触发阈值 |
| reset_to_zero | True | 触发后膜电位是否归零 |
| 归一化方法 | max_norm | 每层权重除以该层最大绝对值 |

### 2.3 代码结构

```python
# ============ 泊松编码 ============
def poisson_encode(pixel_value, num_timesteps):
    """将单个像素值编码为长度为num_timesteps的脉冲序列"""
    return np.random.rand(num_timesteps) < pixel_value

def encode_image(image, num_timesteps):
    """将28×28图像编码为(784, num_timesteps)的脉冲矩阵"""
    return np.array([poisson_encode(p, num_timesteps) for p in image])

# ============ IF神经元 ============
class IFNeuron:
    def __init__(self, weights, bias, threshold=1.0):
        self.W = weights
        self.b = bias
        self.threshold = threshold
        self.V = 0    # 膜电位

    def forward_timestep(self, input_spikes):
        """单时间步前向：输入脉冲 → 累加 → 判断触发"""
        I = np.dot(input_spikes, self.W) + self.b   # 输入电流
        self.V += I                                  # 积分
        output_spikes = (self.V > self.threshold).astype(int)
        self.V[output_spikes > 0] = 0                # 触发后复位
        return output_spikes

# ============ SNN前向传播 ============
class SNN:
    def __init__(self, W1, b1, W2, b2, threshold=1.0):
        self.layer1 = IFNeuron(W1, b1, threshold)
        self.layer2 = IFNeuron(W2, b2, threshold)

    def forward(self, encoded_image, num_timesteps):
        """对一张编码后的图片做SNN推理"""
        spikes_layer1 = np.zeros((300,))
        spikes_layer2 = np.zeros((10,))

        for t in range(num_timesteps):
            # 输入层784个脉冲 → 隐藏层300个IF神经元
            s1 = self.layer1.forward_timestep(encoded_image[:, t])
            spikes_layer1 += s1
            # 隐藏层300个脉冲 → 输出层10个IF神经元
            s2 = self.layer2.forward_timestep(s1)
            spikes_layer2 += s2

        # 输出层脉冲数最多的 = 识别结果
        prediction = np.argmax(spikes_layer2)
        return prediction, spikes_layer1, spikes_layer2
```

### 3.3 子模块1：4×4阵列乘法器

#### 3.3.1 原理

阵列乘法器基于"移位相加"原理：4位 × 4位的乘法分解为4个部分积，每个部分积是被乘数乘以乘数的某一位（用AND门实现），然后按位偏移相加（用全加器/半加器阵列）。

#### 3.3.2 部分积生成（16个AND门）

```
A = a3 a2 a1 a0（被乘数，4位）
B = b3 b2 b1 b0（乘数，4位）

部分积0：a3·b0  a2·b0  a1·b0  a0·b0
部分积1：a3·b1  a2·b1  a1·b1  a0·b1  （左移1位）
部分积2：a3·b2  a2·b2  a1·b2  a0·b2  （左移2位）
部分积3：a3·b3  a2·b3  a1·b3  a0·b3  （左移3位）
```

每个部分积的一位 = 一个AND门。总共16个AND门。

#### 3.3.3 部分积相加（半加器+全加器阵列）

阵列结构示意图（4×4）：

```
           a3·b0  a2·b0  a1·b0  a0·b0
      a3·b1  a2·b1  a1·b1  a0·b1
 + a3·b2  a2·b2  a1·b2  a0·b2
a3·b3  a2·b3  a1·b3  a0·b3
─────────────────────────────
 p7  p6  p5  p4  p3  p2  p1  p0
```

第一行（用半加器HA）：
  HA(a1·b0, a0·b1) → 和给p1，进位给下一列
  HA(a2·b0, a1·b1) → 和给下一行，进位传递
  ...

实际阵列布局如下：

```
列7  列6  列5  列4    列3    列2    列1    列0
│    │    │    │      │      │      │      │
│    │    │    │      │      │      │a0·b0 │→ p0
│    │    │    │      │      │a1·b0 │a0·b1 │
│    │    │    │      │      │ HA   └──────┤
│    │    │    │      │a2·b0 │a1·b1 │Cout   │
│    │    │    │      │ FA   ├──────┤      │
│    │    │    │a3·b0 │a2·b1 │ C    │S→p1  │
│    │    │    │ FA   ├──────┤      │      │
│    │    │a3·b1 │ C  │a2·b2 │...          │
│    │    │ FA   ├────┤                      │
│    │a3·b2 │ C  │...                        │
│    │ FA   ├────┤                            │
│a3·b3 │ C  │                                │
│ HA   ├────┤                                 │
│ C    │                                      │
p7    p6    p5    p4    p3     p2     p1     p0
```

**模块统计**：
- AND门：16个（生成部分积）
- 半加器（HA）：4个
- 全加器（FA）：8个
- 总逻辑门当量：约48个门

#### 3.3.4 半加器门级电路

```
HA(1位输入A, 1位输入B):
  Sum = A XOR B        = (A·!B + !A·B)       → 6个晶体管（CMOS XOR）
  Carry = A AND B      → 6个晶体管（CMOS AND）
```

#### 3.3.5 全加器门级电路

```
FA(1位输入A, B, Cin):
  Sum = A XOR B XOR Cin                 → ~12个晶体管
  Carry = (A AND B) OR (Cin AND (A XOR B))  → ~12个晶体管
```

### 3.4 子模块2：4位CLA超前进位加法器

#### 3.4.1 原理

CLA的关键是并行计算进位，不依赖逐级传播。用生成信号G和传播信号P：

```
对于第i位:
  G_i = A_i AND B_i    (进位生成：不管输入进位，这一位本身就会产生进位)
  P_i = A_i XOR B_i    (进位传播：如果有输入进位，这一位会传递下去)
```

进位公式（并行计算）：
```
C_0 = Cin
C_1 = G_0 + P_0·Cin
C_2 = G_1 + P_1·G_0 + P_1·P_0·Cin
C_3 = G_2 + P_2·G_1 + P_2·P_1·G_0 + P_2·P_1·P_0·Cin
C_4 = Cout = G_3 + P_3·G_2 + P_3·P_2·G_1 + P_3·P_2·P_1·G_0 + P_3·P_2·P_1·P_0·Cin
```

Sum输出：
```
S_i = P_i XOR C_i
```

#### 3.4.2 门级电路实现

**4位CLA的进位逻辑（Carry Lookahead Logic）**：

```
C_1 = G_0 | (P_0 & Cin)                    → 1个OR + 1个AND
C_2 = G_1 | (P_1 & G_0) | (P_1 & P_0 & Cin)  → 2个OR + 3个AND
C_3 = G_2 | (P_2 & G_1) | (P_2 & P_1 & G_0) | (P_2 & P_1 & P_0 & Cin)
                                            → 3个OR + 6个AND
C_4 = G_3 | (P_3 & G_2) | (P_3 & P_2 & G_1) | (P_3 & P_2 & P_1 & G_0)
      | (P_3 & P_2 & P_1 & P_0 & Cin)       → 4个OR + 10个AND
```

**延迟分析**（基于单元4-6 Slide 11方法）：
```
CLA总延迟 ≈ 2×t_xor + 1×t_or + 1×t_and
         ≈ 延迟约3-5个逻辑门级
对比RCA的4位延迟 ≈ 4 × 2×t_xor ≈ 8个逻辑门级
CLA约比RCA快2倍
```

## 第四章 硬件实施：SNN-IF脉冲神经元电路

### 4.1 任务概述

在Cadence Virtuoso上分两阶段搭建SNN-IF脉冲神经元电路。第一阶段（积分器）：验证膜电位累积功能；第二阶段（IF神经元）：加入比较器和复位逻辑，完成完整的积分-触发-复位机制。

### 4.2 第一阶段：积分器（Integrator）

#### 4.2.1 功能

```
每个时钟周期：V[t+1] = V[t] + I[t]
其中 I[t] = input_spike × weight
```

#### 4.2.2 电路实现

```
                   ┌─────────────┐
input_spike ──────→│ MUX         │
                   │  SEL  │     │
weight ────────────→│ IN1   │ OUT │
0 ─────────────────→│ IN0   │     │
                   └───┬─────────┘
                       │ (有脉冲=加载weight，无脉冲=加载0)
                       │
                       ▼
                   ┌─────────────┐
                   │ 加法器       │
                   │ A  │ B      │
                   └──┬─┬──┬────┘
                      │ │  │
          ┌───────────┘ │  └──────────────┐
          ▼             ▼                 ▼
      ┌────────┐    ┌───────────┐     ┌────┐
      │寄存器  │    │ V(t+1)    │     │CLK │
      │D   Q   │◄───┤           │     └────┘
      │CLR     │    └───────────┘        │
      └───┬────┘                         │
          │(V) 膜电位                     │
          └────────────┬─────────────────┘
                       │ 反馈到加法器A输入
                       │
                       ▼
                  ┌─────────┐
                  │  输出V  │（膜电位值，供第二阶段使用）
                  └─────────┘
```

#### 4.2.3 真值表验证

| 时钟周期 | input_spike | weight | V_old | V_new |
|---|---|---|---|---|
| 1 | 1 | 5 | 0 | 5 |
| 2 | 1 | 5 | 5 | 10 |
| 3 | 0 | 5 | 10 | 10 |
| 4 | 1 | 5 | 10 | 15 |

**验证目标**：膜电位V能正确累积输入脉冲×权重的乘积。

### 4.3 第二阶段：IF脉冲神经元

#### 4.3.1 功能

```
每个时钟周期：
  Step 1: V[t+1] = V[t] + I[t]（积分，复用积分器）
  Step 2: 如果 V[t+1] > threshold → 输出脉冲1，V复位
          否则 → 输出脉冲0，V保持不变
```

#### 4.3.2 电路实现（在积分器基础上增加）

```
                    ┌───────────┐
    ┌──────────────→│ 比较器     │
    │               │ A     B   │
    │               │ V  threshold│
    │               └─────┬─────┘
    │                     │ A > B ?
    │                     ▼
    │               ┌────────────┐
    │               │ 输出脉冲    │
    │               │ (spike_out)│
    │               └──────┬─────┘
    │                      │
    │                      ▼
    │                 ┌───────────────┐
    │                 │ 复位控制       │
    │                 │ (spike_out = 1 │
    │                 │  时触发)       │
    │                 └───────┬───────┘
    │                         │
    │                         ▼
    │                    ┌────────────┐
    └────────────────────┤ 寄存器CLR  │
                         │ (清零V)    │
                         └────────────┘
```

#### 4.3.3 完整电路信号流

```
input_spike ──→ MUX ──→ 加法器 ──→ 寄存器(V) ──→ 比较器 ──→ spike_out
                  ↑       ↑            │           ↑
                  │       │            │        threshold
                  └─weight┘            │
                                       │
                              ┌────────┘
                              ▼
                           复位控制
                           (spike_out=1时清零)
                    ┌───────────┘
                    ▼
                寄存器CLR引脚
```

#### 4.3.4 时序控制（关键难点）

```
每个时钟周期上升沿触发：

  Clock Cycle 1:
    ① CLK上升沿：寄存器输出 V_old
    ② 组合逻辑：MUX选择(weight或0) → 加法器计算 V_new = V_old + I
    ③ 组合逻辑：比较器判断 V_new > threshold？
       - 如果 V_new > threshold: spike_out=1，寄存器CLR信号=1
       - 否则: spike_out=0，寄存器CLR信号=0
    (下一个CLK上升沿：如果CLR有效，寄存器清零；否则寄存V_new)
```

**关键**：加法器和比较器是组合逻辑，在同一个时钟周期内完成计算和比较。复位信号与CLK同步，在下一个时钟沿生效。

#### 4.3.5 真值表验证

| 时钟 | input | weight | V_old | I | V_new | threshold | spike_out | V_next |
|---|---|---|---|---|---|---|---|---|
| 1 | 1 | 5 | 0 | 5 | 5 | 10 | 0 | 5 |
| 2 | 1 | 5 | 5 | 5 | 10 | 10 | 1 | **0**（复位） |
| 3 | 0 | 5 | 0 | 0 | 0 | 10 | 0 | 0 |
| 4 | 1 | 5 | 0 | 5 | 5 | 10 | 0 | 5 |
| 5 | 1 | 5 | 5 | 5 | 10 | 10 | 1 | **0**（复位） |

**验证目标**：
- V累积到阈值后触发脉冲
- 触发后V立即复位
- 复位后重新开始累积

### 4.4 Cadence搭建步骤

```
Level 1: 积分器（从已有元件搭建）
  ├── MUX：传输门实现（2个传输门+1个反相器）
  ├── 加法器：使用ANN-MAC中已搭的半加器+全加器
  ├── 寄存器：使用D触发器（教学中已建）
  └── 时钟信号：从testbench提供10MHz方波

Level 2: IF神经元（在积分器上增加）
  ├── 比较器：多个4位比较的级联结构
  │   └── 逐位比较：A[3] vs B[3] → A[2] vs B[2] → ...
  ├── 复位逻辑：spike_out与寄存器CLR连接
  └── 阈值寄存器：外部输入到比较器B端
```

```
测试用例1（基本触发）：
  输入：每周期一个脉冲，weight=5，threshold=10

  检验：V在周期1=5，周期2=10→触发，周期3=0

  输入：每周期一个脉冲，weight=5，threshold=10
```

## 第六章 准确率-功耗trade-off拟合

### 6.1 方法

以ANN为基准（准确率93%，功耗100%），在不同时间步数下收集SNN的准确率数据和对应的功耗数据。

### 6.2 数据收集计划

| 数据点 | 条件 | 准确率 | 功耗(mW) | 功耗节省率 |
|---|---|---|---|---|
| 1（基线） | ANN | ~93% | MAC功耗 = P_mac | 0% |
| 2 | SNN, T=100步 | ~88% | IF功耗 × T × 稀疏率 | ? |
| 3 | SNN, T=50步 | ~86% | IF功耗 × T × 稀疏率 | ? |
| 4 | SNN, T=30步 | ~84% | IF功耗 × T × 稀疏率 | ? |
| 5 | SNN, T=10步 | ~80% | IF功耗 × T × 稀疏率 | ? |

### 6.3 拟合方法

```python
# 数据点
accuracies = [93, 88, 86, 84, 80]   # SNN在不同参数下的准确率
power_savings = [0, 15, 25, 35, 50]  # 功耗节省百分比

# 线性拟合：power_saving = k × (93 - accuracy)
# k = 功耗每降低1%准确率能省多少功耗
import numpy as np
x = np.array([93 - a for a in accuracies])  # 准确率下降幅度
y = np.array(power_savings)                 # 功耗节省率
k = np.polyfit(x, y, 1)[0]                  # 拟合斜率
print(f"每降低1%准确率，可节省约{k:.1f}%功耗")

# 画图
import matplotlib.pyplot as plt
plt.plot(x, y, 'o-')
plt.xlabel('准确率下降 (%)')
plt.ylabel('功耗节省率 (%)')
plt.title('SNN准确率-功耗 trade-off 曲线')
plt.grid(True)
plt.savefig('tradeoff_curve.png')
```

### 6.4 最终结论

```
本课题的最终结论是：对于MNIST手写数字识别任务，
SNN-IF脉冲神经元相比ANN-MAC乘加单元，
每降低1%的识别准确率，大约能节省___%的硬件功耗。

这一量化关系是课堂上"SNN更省电"这一定性结论的具体化，
为类脑芯片的能效设计提供了参考数据。
```

## 第八章 风险点与质量控制

### 8.1 关键风险

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| SNN准确率过低 | 中 | trade-off曲线数据点不够 | 多测几组时间步数（10/20/30/50/100），总有一组有意义 |
| IF神经元时序不通过 | 低 | 电路不能正确触发 | 从积分器退一步验证；检查CLK与CLR的时序关系 |
| Cadence仿真不收敛 | 低 | 无法提取精确功耗 | 增加仿真时间；检查激励信号是否合理 |
| ANN训练无法达到93% | 低 | 基线不成立 | 增加epoch到100；尝试调低lr到0.01 |
