## 第一章 软件实施：ANN-MLP训练

### 1.1 任务概述

训练一个三层全连接神经网络（MLP 784-300-10，**ReLU激活函数，无BatchNorm/Dropout，纯numpy手写实现**），在MNIST手写数字数据集上达到≥95%的测试准确率，作为后续SNN对比的软件基线。

**手写实现说明**：为满足答辩时能逐行讲解计算原理的要求，本课题的ANN训练代码全部使用 numpy 手动编写前向传播、反向传播（链式法则逐层求梯度）和参数更新，不使用 PyTorch/TensorFlow 等高级库。激活函数选用 ReLU（非 sigmoid），原因是 ANN-to-SNN 转换要求 ReLU 的非负无界输出与 IF 神经元的脉冲发放率建立线性映射关系。

### 1.8 反向传播的手写推导（答辩核心知识点）

本节列出 `train_ann_relu.py` 中每个梯度计算的数学推导，确保答辩时能逐行讲清原理。

#### 1.8.1 前向传播公式

```
z1 = x · W1 + b1        (全连接层1，输入784 → 隐藏层300)
a1 = ReLU(z1)            (ReLU激活：max(0, z1))
z2 = a1 · W2 + b2       (全连接层2，隐藏层300 → 输出10)
p  = Softmax(z2)         (将logits转为概率分布)
L  = -1/N Σ log(p_i[y_i])  (交叉熵损失)
```

#### 1.8.2 ReLU 激活函数及其导数

```
ReLU:     f(z) = max(0, z)
导数:     f'(z) = 1  (z > 0)
         f'(z) = 0  (z ≤ 0)

为什么用 ReLU 而非 sigmoid？
- ANN-to-SNN 转换要求激活函数输出非负有界，与 IF 脉冲发放率成正比
- sigmoid 输出有界[0,1]，不同输入可能产生相同输出——丢失信息
- ReLU 梯度简单（0或1），计算快，无 sigmoid 的梯度饱和问题
- 注意：ReLU 需要 Kaiming 初始化（非 randn*0.01），否则大量神经元"死亡"
```

#### 1.8.3 Softmax + CrossEntropy 联合梯度（输出层）

这是推导中最关键的一步。单独推导 Softmax 和 CrossEntropy 都很复杂，但**两者结合后有一个极其简洁的联合梯度**：

```
∂L/∂z2 = softmax(z2) - y_onehot = p - y_onehot
```

推导过程（答辩时可展开讲）：

```
1. CrossEntropy: L = -Σ y_k · log(p_k), 其中 p_k = softmax(z2_k)
2. 对 z2_j 求偏导: ∂L/∂z2_j = Σ_k ∂L/∂p_k · ∂p_k/∂z2_j
3. Softmax 导数: ∂p_k/∂z2_j = p_k·(δ_kj - p_j)  (δ_kj = 1 if k=j else 0)
4. 代入后化简（利用 Σ_k y_k = 1, Σ_k p_k = 1）:
   ∂L/∂z2_j = p_j - y_j
```

**为什么这个简化很重要**: 有了这个公式，输出层的反向传播只需要一行代码 `dz2 = probs - y_onehot`，无需手动推导 Softmax 的雅可比矩阵。

#### 1.8.4 链式法则：隐藏层梯度

```
(1) 从输出层误差反向传播到隐藏层:
    ∂L/∂a1 = ∂L/∂z2 · W2^T          = dz2 · W2^T

(2) 通过 ReLU 激活函数:
    ∂L/∂z1 = ∂L/∂a1 ⊙ ReLU'(z1)    = dz2·W2^T * (z1 > 0)
    其中 ⊙ 表示逐元素乘法（Hadamard积）

(3) 求出权重和偏置的梯度:
    ∂L/∂W1 = x^T · (∂L/∂z1) / N   = x^T · dz1 / N
    ∂L/∂b1 = Σ(∂L/∂z1) / N         = mean(dz1, axis=0)
    ∂L/∂W2 = a1^T · dz2 / N
    ∂L/∂b2 = Σ(dz2) / N             = mean(dz2, axis=0)
```

#### 1.8.5 参数更新（SGD梯度下降）

本代码使用最基础的 **SGD（随机梯度下降）**，而非 Adam。这是为了答辩时能讲清最简单的优化原理。注意：文档 1.4 节中 `learning_rate=0.01` 就是 SGD 的学习率（不是 Adam 的）。

```
W1_new = W1 - lr × ∂L/∂W1
b1_new = b1 - lr × ∂L/∂b1
W2_new = W2 - lr × ∂L/∂W2
b2_new = b2 - lr × ∂L/∂b2
```

**答辩要点**: 能讲清楚以下 3 个关键公式即可：

1. **Softmax+CrossEntropy 联合梯度**: `dz2 = probs - y_onehot`（一行代码，背后是最优美的简化）
2. **ReLU 反向传播**: `dz1 = (dz2 · W2^T) * (z1 > 0)`（只有激活的神经元才传梯度）
3. **链式法则递推**: 从输出层误差逐层回传，每层用 `W^T` 转置矩阵传播误差

## 第二章 软件实施：ANN-to-SNN转换

### 2.1 任务概述

将训练好的ANN权重转换为SNN格式，用IF脉冲神经元替代ReLU激活函数，在MNIST上验证SNN的识别准确率（目标≥85%），统计脉冲稀疏性。

**前提条件（三要素）**：
1. ANN 使用 **ReLU** 激活函数（已满足——`train_ann_relu.py`）
2. 输入归一化到 **[0,1]** 区间（已满足——/255 归一化，非 z-score）
3. 网络**无 BatchNorm/Dropout**（已满足——784-300-10 纯全连接）

### 2.2 ANN-to-SNN转换算法

### 2.2.1 核心思想

不从头训练SNN，而是直接复用已训练好的ANN浮点权重。ANN的激活值（ReLU输出）替换为IF神经元的脉冲发放率（Firing Rate）。原理是：输入图片编码为脉冲序列后，IF神经元的膜电位累积速度与ANN的激活值成正比。

### 2.2.2 转换步骤

```
Step 1: 加载ANN权重
  W1, b1, W2, b2 ← 从ann_mnist_weights_relu.npz加载

Step 2: 权重归一化
  - 原因：IF神经元的脉冲发放率与输入权重的幅值相关
  - 方法：找到每层权重的最大绝对值max_W，W_norm = W / max_W
  - 阈值theta_IF通常设为1.0

Step 3: 泊松编码（将MNIST图片转为脉冲序列）
  对于每个像素值pixel ∈ [0, 1]（已经除以255）：
    在每个时间步t，生成一个随机数rand ∈ [0, 1]
    如果rand < pixel → 在时间步t发放一个脉冲（spike = 1）
    否则 → 不发放（spike = 0）
  结果：一张28×28=784像素的图片，被编码为784个泊松脉冲序列
  每个序列长度 = num_timesteps

Step 4: IF神经元前向传播（替代ANN的ReLU）
  第i个神经元的膜电位 V_i 初始为0
  在每个时间步t：
    输入脉冲 × 归一化权重 → 累加到V_i
    如果 V_i >= 阈值theta → 发放一个脉冲，V_i 在下一时间步重置为0
    否则不发放
  N个时间步后，统计每个神经元的脉冲发放总数
  输出层10个神经元中，发放次数最多的 = 识别结果

Step 5: 准确率评估
  遍历MNIST测试集全部10000张图片
  对比预测值与真实标签
```

### 2.2.3 关键参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| num_timesteps | 50 | 每张图片仿真的时间步数（越多越准但越慢） |
| threshold | 1.0 | IF神经元触发阈值 |
| reset_to_zero | True | 触发后膜电位是否归零 |
| 归一化方法(主) | max_norm | 每层权重除以该层最大绝对值。默认使用，简单快速 |
| 归一化方法(备) | data_based | 训练集激活值的99.9%分位数作为缩放因子。当max_norm下准确率不理想时启用，通常可提升2-5个百分点（见2.2.4节） |

### 2.2.4 权重归一化详细步骤

#### 方法1：max_norm（默认使用）

```python
def max_norm_normalize(W1, b1, W2, b2):
    # 第一层：除以W1的最大绝对值
    scale1 = np.max(np.abs(W1))
    W1_norm = W1 / scale1
    b1_norm = b1 / scale1
    # 第二层：除以W2的最大绝对值
    scale2 = np.max(np.abs(W2))
    W2_norm = W2 / scale2
    b2_norm = b2 / scale2
    return (W1_norm, b1_norm), (W2_norm, b2_norm), (scale1, scale2)
```

原理：将权重缩放到 [0, 1] 范围，使 IF 神经元的膜电位累积速度在合理范围内，阈值 theta=1.0 恰好能工作。

#### 方法2：data-based 99.9%分位归一化（备选，准确率<85%时启用）

当 max_norm 归一化后 SNN 准确率不达标时，采用更精细的 data-based normalization：

```python
def data_based_normalize(W1, b1, W2, b2, X_train, Vth=1.0, percentile=99.9, max_samples=5000):
    # 1. 在训练集上跑 ANN 前向传播，记录每层 ReLU 输出
    n_sample = min(max_samples, X_train.shape[0])
    X = X_train[:n_sample].astype(np.float32)

    z1 = np.dot(X, W1) + b1
    a1 = np.maximum(0, z1)  # ReLU

    # 2. 计算 99.9% 分位数作为缩放因子
    max_act_l1 = np.percentile(a1, percentile)
    scale1 = Vth / max(max_act_l1, 1e-8)  # 防止除零

    # 3. 用分位数缩放第 1 层权重
    W1_norm = W1 * scale1
    b1_norm = b1 * scale1

    # 4. 用归一化后的第 1 层重新计算第 2 层激活值
    z1_norm = np.dot(X, W1_norm) + b1_norm
    a1_norm = np.maximum(0, z1_norm)
    z2 = np.dot(a1_norm, W2) + b2
    a2 = np.maximum(0, z2)  # ReLU（输出层也走 ReLU 风格前向）

    max_act_l2 = np.percentile(a2, percentile)
    scale2 = Vth / max(max_act_l2, 1e-8)

    # 5. 缩放第 2 层权重
    W2_norm = W2 * scale2
    b2_norm = b2 * scale2

    return (W1_norm, b1_norm), (W2_norm, b2_norm)
```

**为什么用 99.9% 而非最大值**：
- 最大值可能被少数异常大的激活值拉偏，导致大部分输入对应的膜电位偏低
- 99.9% 分位数对异常值更鲁棒，确保 99.9% 的正常输入都能有效驱动 IF 神经元

**启用条件**：max_norm 归一化后 SNN 测试准确率低于预期时，可切换到 data-based 方法。在本课题中，data_based 在 T=50、Vth=1.0 配置下即可达到约 95.83% 的测试准确率。

### 2.3 代码结构

```python
# ============ 泊松编码 ============
def poisson_encode(pixel_value, num_timesteps):
    """将单个像素值编码为长度为num_timesteps的脉冲序列"""
    return np.random.rand(num_timesteps) < pixel_value

def encode_image(image, num_timesteps):
    """将28×28图像编码为(784, num_timesteps)的脉冲矩阵"""
    return np.array([poisson_encode(p, num_timesteps) for p in image])

# ============ IF神经元 ============
class IFLayer:
    def __init__(self, weights, bias, threshold=1.0):
        self.W = weights
        self.b = bias
        self.threshold = threshold
        self.V = 0    # 膜电位

    def forward(self, input_spikes):
        """单时间步前向：输入脉冲 → 累加 → 判断触发"""
        I = np.dot(input_spikes, self.W) + self.b   # 输入电流
        self.V += I                                  # 积分
        output_spikes = (self.V >= self.threshold).astype(int)
        self.V[output_spikes > 0] = 0                # 触发后复位
        return output_spikes

# ============ SNN前向传播 ============
class SNN:
    def __init__(self, W1, b1, W2, b2, threshold=1.0):
        self.layer1 = IFLayer(W1, b1, threshold)
        self.layer2 = IFLayer(W2, b2, threshold)

    def forward(self, encoded_image, num_timesteps):
        """对一张编码后的图片做SNN推理"""
        spikes_layer1 = np.zeros((300,))
        spikes_layer2 = np.zeros((10,))

        for t in range(num_timesteps):
            # 输入层784个脉冲 → 隐藏层300个IF神经元
            s1 = self.layer1.forward(encoded_image[:, t])
            spikes_layer1 += s1
            # 隐藏层300个脉冲 → 输出层10个IF神经元
            s2 = self.layer2.forward(s1)
            spikes_layer2 += s2

        # 输出层脉冲数最多的 = 识别结果
        prediction = np.argmax(spikes_layer2)
        return prediction, spikes_layer1, spikes_layer2
```

**注意**：以上代码中的 IF 神经元是**软件仿真**版本（Python 层），处理的是向量化的全连接计算。Cadence 硬件实现聚焦于**单神经元级别的 IF 原理验证**（见第四章关于实现范围的说明）。

## 第三章 硬件实施：ANN-MAC单元（Cadence Virtuoso）

### 3.1 任务概述

在Cadence Virtuoso上搭建一个4×4阵列乘法器 + 4位CLA超前进位加法器 + 累加寄存器，构成一个完整的 ANN-MAC 乘加单元。仿真验证功能正确性，提取延迟(tpLH/tpHL)、动态功耗、晶体管数。

**实现范围声明**：本 MAC 单元为**原理演示单元**（教学验证），非完整精度 ANN 计算单元。原因如下：
- 4×4 乘法器输出最高可达 225（8 位），但 CLA 和累加寄存器仅 4 位（最大可表示 15）。实际 ANN 的 MAC 运算（784 个输入加权求和）需 12-16 位累加器，4 位累加器在两次累加后即溢出。
- 本章聚焦于验证乘法器+CLA+寄存器协同工作的正确性和测量各子模块的延迟/功耗/晶体管数，为第四章的 SNN-MAC 单元对比提供基线。
- 完整精度的 MAC 单元（扩展到 12-16 位）是规模扩展问题，核心电路拓扑与本单元完全一致。实测的 4 位基本单元延迟和功耗可线性外推至全精度版本。

因此，测试用例仅使用小值输入（乘积 ≤ 15），确保功能可验证。3.6 节的测试用例已按此原则调整。

### 3.3 子模块1：4×4阵列乘法器

#### 3.3.1 原理

阵列乘法器基于"移位相加"原理：4位 × 4位的乘法分解为4个部分积，每个部分积是被乘数乘以乘数的某一位（用AND门实现），然后按位偏移相加（用全加器/半加器阵列）。

#### 3.3.2 部分积生成（16个AND门）

```
A = a3 a2 a1 a0（被乘数，4位）
B = b3 b2 b1 b0（乘数，4位）

部分积0：a3·b0  a2·b0  a1·b0  a0·b0
部分积1：a3·b1  a2·b1  a1·b1  a0·b1  （左移1位）
部分积2：a3·b2  a2·b2  a1·b2  a0·b2  （左移2位）
部分积3：a3·b3  a2·b3  a1·b3  a0·b3  （左移3位）
```

每个部分积的一位 = 一个AND门。总共16个AND门。

#### 3.3.3 部分积相加（半加器+全加器阵列）

阵列结构示意图（4×4）：

```
           a3·b0  a2·b0  a1·b0  a0·b0
      a3·b1  a2·b1  a1·b1  a0·b1
 + a3·b2  a2·b2  a1·b2  a0·b2
a3·b3  a2·b3  a1·b3  a0·b3
─────────────────────────────
 p7  p6  p5  p4  p3  p2  p1  p0
```

第一行（用半加器HA）：
  HA(a1·b0, a0·b1) → 和给p1，进位给下一列
  HA(a2·b0, a1·b1) → 和给下一行，进位传递
  ...

实际阵列布局如下：

```
列7  列6  列5  列4    列3    列2    列1    列0
│    │    │    │      │      │      │      │
│    │    │    │      │      │      │a0·b0 │→ p0
│    │    │    │      │      │a1·b0 │a0·b1 │
│    │    │    │      │      │ HA   └──────┤
│    │    │    │      │a2·b0 │a1·b1 │Cout   │
│    │    │    │      │ FA   ├──────┤      │
│    │    │    │a3·b0 │a2·b1 │ C    │S→p1  │
│    │    │    │ FA   ├──────┤      │      │
│    │    │a3·b1 │ C  │a2·b2 │...          │
│    │    │ FA   ├────┤                      │
│    │a3·b2 │ C  │...                        │
│    │ FA   ├────┤                            │
│a3·b3 │ C  │                                │
│ HA   ├────┤                                 │
│ C    │                                      │
p7    p6    p5    p4    p3     p2     p1     p0
```

**模块统计**：
- AND门：16个（生成部分积，每个 6T = NAND2(4T) + INV(2T)）
- 半加器（HA）：4个（每个 ~14-18T，见 3.3.4 节）
- 全加器（FA）：8个（每个 ~28-30T，见 3.3.5 节）
- 总晶体管数（估算）：16×6 + 4×18 + 8×30 = 96 + 72 + 240 ≈ **408T**（互补 CMOS XOR 实现）
- 总逻辑门当量：约100-130个基础门 (16 AND + 4 HA + 8 FA 的门级子单元展开)
- 备注：晶体管数以 Cadence 原理图实测为准；此处为门级展开保守估计。

#### 3.3.4 半加器门级电路

```
HA(1位输入A, 1位输入B):
  Sum = A XOR B     = (A·!B + !A·B)       → ~8个晶体管（传输门 XOR, 6T）
                                               或 ~12个晶体管（互补 CMOS XOR）
  Carry = A AND B   = NAND(A,B) + INV     → 6个晶体管（4T NAND + 2T INV）

半加器总晶体管数: ~14T（传输门 XOR）或 ~18T（互补 CMOS XOR）
```

**说明**：XOR 的晶体管数取决于电路拓扑。6T 传输门 XOR 面积最小但有电平退化（不能直接级联驱动）；互补 CMOS XOR（8-12T）驱动能力更强但面积更大。本课题在 Cadence 中具体实现时按 PDK 提供的标准单元或自搭电路确定。文档标注以互补 CMOS XOR 为主要参考（~12T XOR + 6T AND = ~18T）。AND = NAND(4T) + INV(2T) = 6T 在各节中统一。

#### 3.3.5 全加器门级电路

```
FA(1位输入A, B, Cin):
  Sum = A XOR B XOR Cin                 → ~12个晶体管（2 级 XOR）
  Carry = (A AND B) OR (Cin AND (A XOR B))
    - (A AND B): 6T (NAND2+INV)
    - Cin AND (A^B): 6T (NAND2+INV)     ← A^B 与 Sum 路径共享
    - OR: 6T (NOR2+INV)
    Carry 合计: ~18T

全加器总晶体管数: ~28-30T（互补 CMOS XOR 实现）
```

**注意**：文档先前标注 ~24T 仅适用于最紧凑的传输门 XOR 实现。此处调整为更保守的 ~28-30T 估算，与多数教材（如 Rabaey "Digital Integrated Circuits"）一致。

### 3.4 子模块2：4位CLA超前进位加法器

#### 3.4.1 原理

CLA的关键是并行计算进位，不依赖逐级传播。用生成信号G和传播信号P：

```
对于第i位:
  G_i = A_i AND B_i    (进位生成：不管输入进位，这一位本身就会产生进位)
  P_i = A_i XOR B_i    (进位传播：如果有输入进位，这一位会传递下去)
```

进位公式（并行计算）：
```
C_0 = Cin
C_1 = G_0 + P_0·Cin
C_2 = G_1 + P_1·G_0 + P_1·P_0·Cin
C_3 = G_2 + P_2·G_1 + P_2·P_1·G_0 + P_2·P_1·P_0·Cin
C_4 = Cout = G_3 + P_3·G_2 + P_3·P_2·G_1 + P_3·P_2·P_1·G_0 + P_3·P_2·P_1·P_0·Cin
```

Sum输出：
```
S_i = P_i XOR C_i
```

#### 3.4.2 门级电路实现

**4位CLA的进位逻辑（Carry Lookahead Logic）**：

**符号说明**：3.4.1 节使用布尔代数符号 `·` (AND) 和 `+` (OR)（学术界传统），本节门级实现保留 C/Verilog 风格符号 `&` (AND) 和 `|` (OR) 以贴近硬件描述习惯。两者等价：`A·B = A&B`, `A+B = A|B`。

```
C_1 = G_0 | (P_0 & Cin)                    → 1个OR + 1个AND
C_2 = G_1 | (P_1 & G_0) | (P_1 & P_0 & Cin)  → 2个OR + 3个AND
C_3 = G_2 | (P_2 & G_1) | (P_2 & P_1 & G_0) | (P_2 & P_1 & P_0 & Cin)
                                            → 3个OR + 6个AND
C_4 = G_3 | (P_3 & G_2) | (P_3 & P_2 & G_1) | (P_3 & P_2 & P_1 & G_0)
      | (P_3 & P_2 & P_1 & P_0 & Cin)       → 4个OR + 10个AND
```

**延迟分析**（基于单元4-6 Slide 11方法）：

以下分步估算 CLA 的完整延迟路径（从输入到 Sum 输出）：

```
(1) P_i/G_i 生成: t_pg = 1 级 XOR（并行计算 4 位 P_i）
(2) 进位查找逻辑(C_1~C_4): 最长路径为 P_3·P_2·P_1·P_0·Cin（4 级 AND）+ OR
    t_cla_carry ≈ 2-3 级逻辑门
(3) Sum 输出(S_i = P_i XOR C_i): t_sum = 1 级 XOR
(4) CLA 总延迟: t_cla_total ≈ t_pg + t_cla_carry + t_sum ≈ 4-6 个逻辑门级
```

**注意**: 以上为基于 2 输入门的估计值。实际延迟取决于 CMOS 门实现（多输入门 vs 2 输入门级联）、扇出负载和晶体管尺寸。

**与 RCA 对比**（4 位）：
```
4 位 RCA 约 8-10 个逻辑门级（每个 FA 进位传播约 2-3 个门级 × 4 级）
4 位 CLA 约 4-6 个逻辑门级
加速比约 1.5-2 倍（非 2 倍以上，因为 4 位 CLA 的进位链仍有门级深度）
```

**基本门延迟参考值（TSMC 65nm / gpdk90 典型，扇出=4）**：
```
INV: ~10-20 ps
NAND2: ~15-25 ps
XOR2: ~30-50 ps
```
实际延迟应在 Cadence 中通过 Spectre 仿真测量 tpLH/tpHL 确认。以上为预估值，以实测为准。

**注意**: 以上门数按各项独立计算统计（最坏情况）。实际实现中可通过共享中间乘积项减少约 30-40% 的门数。例如 P_3·P_2 在 C_3 和 C_4 中均可复用；P_3·P_2·P_1·P_0 最多计算一次。

### 3.8.1 静态功耗测量步骤

静态功耗是晶体管在无信号切换时的漏电流功耗，需从总功耗中扣除才能得到准确的动态功耗。

**测量步骤**：
1. 在 ADE 中设置瞬态（Transient）分析，**所有输入信号固定为已知逻辑电平**：
   - 对每个输入引脚明确指定固定电平（0V = GND 或 VDD），建议测两组：
     * 全部输入接 GND（全 0 输入向量）
     * 全部输入接 VDD（全 1 输入向量）
   - 取两组静态电流中较大者作为保守估计
   - （更精确的做法：遍历多种输入组合，取平均——CMOS 电路中 stack effect 导致不同输入组合下漏电流可能相差 2-5 倍）
2. 运行仿真，测量电源 VDD 上的平均电流 `I_static`
   - 在 ADE Calculator 中：`average(IT("/VDD"))`
3. 静态功耗 `P_static = VDD × I_static`
4. 正常功能仿真中测得的总功耗 `P_total` 减去静态功耗即为动态功耗：
   `P_dynamic = P_total - P_static`

**测量前提**：仿真应在所有信号稳定后再开始采样（跳过后始瞬态），建议跳过前 20-50 ns。

**为什么静态功耗对 SNN 对比很重要**：
- 事件驱动的功耗优势主要体现在动态功耗（翻转功耗）部分
- SNN 脉冲稀疏时，动态功耗占比下降，静态功耗占比上升
- **答辩时需能解释**：SNN 的优势是动态功耗，但在极低活动率下静态功耗会成为瓶颈——这是类脑芯片实际设计的 trade-off

## 第四章 硬件实施：SNN-IF脉冲神经元电路

### 4.1 任务概述

在Cadence Virtuoso上分两阶段搭建SNN-IF脉冲神经元电路。第一阶段（积分器）：验证膜电位累积功能；第二阶段（IF神经元）：加入比较器和复位逻辑，完成完整的积分-触发-复位机制。

**验证范围说明**：本阶段在 Cadence 上实现**单神经元级别**的 IF 电路。电路接收单路输入脉冲(spike)和单路权重(weight)，通过 MUX+加法器+寄存器+比较器链路完成积分-触发-复位。这是 SNN 全连接层的最小可验证单元——完整隐藏层（300 个神经元，每个接收 784 路输入脉冲）的多输入连接是规模扩展问题，其核心原理与本阶段的单神经元验证完全一致。单神经元验证得到的功耗数据可通过线性外推估算全层功耗（见 5.2.1 节）。

### 4.2 第一阶段：积分器（Integrator）

#### 4.2.1 功能

```
每个时钟周期：V[t+1] = V[t] + I[t]
其中 I[t] = input_spike × weight
```

#### 4.2.2 电路实现

```
                   ┌─────────────┐
input_spike ──────→│ MUX         │
                   │  SEL  │     │
weight ────────────→│ IN1   │ OUT │
0 ─────────────────→│ IN0   │     │
                   └───┬─────────┘
                       │ (有脉冲=加载weight，无脉冲=加载0)
                       │
                       ▼
                   ┌─────────────┐
                   │ 加法器       │
                   │ A  │ B      │
                   └──┬─┬──┬────┘
                      │ │  │
          ┌───────────┘ │  └──────────────┐
          ▼             ▼                 ▼
      ┌────────┐    ┌───────────┐     ┌────┐
      │寄存器  │    │ V(t+1)    │     │CLK │
      │D   Q   │◄───┤           │     └────┘
      │CLR     │    └───────────┘        │
      └───┬────┘                         │
          │(V) 膜电位                     │
          └────────────┬─────────────────┘
                       │ 反馈到加法器A输入
                       │
                       ▼
                  ┌─────────┐
                  │  输出V  │（膜电位值，供第二阶段使用）
                  └─────────┘
```

**MUX 位宽说明**：图中 `input_spike` 是 1-bit 脉冲，`weight` 是多 bit 定点数（如 4-bit），因此 MUX 的数据输入端也是多 bit 宽。硬件实现上相当于 N 个 1-bit 2选1 MUX 共享同一个选择信号 `input_spike`。例如 4-bit 权重需要 4 个并行 MUX，输出 4-bit 的 `I[t]`。

#### 4.2.3 真值表验证

| 时钟周期 | input_spike | weight | V_old | V_new |
|---|---|---|---|---|
| 1 | 1 | 5 | 0 | 5 |
| 2 | 1 | 5 | 5 | 10 |
| 3 | 0 | 5 | 10 | 10 |
| 4 | 1 | 5 | 10 | 15 |

**验证目标**：膜电位V能正确累积输入脉冲×权重的乘积。

#### 4.2.4 加法器溢出与位宽

单输入演示中，weight 用 4-bit 表示（范围 0~15），膜电位寄存器也用 4-bit。真实 SNN 隐藏层接收 784 个输入，累加和可能达到 `784 × 15 ≈ 11760`，远超 4-bit 范围。因此完整层实现必须：

1. **扩展累加器位宽**：根据最大可能累加值选择位宽（如 12-16 bit）；
2. **或加入饱和处理**：当 `V_new` 超过上限时令其为上限，避免回绕导致错误触发。

Cadence 演示单元保持 4-bit，测试用例限制 weight 较小、输入脉冲数少，确保无溢出。

### 4.3 第二阶段：IF脉冲神经元

#### 4.3.1 功能

```
每个时钟周期：
  Step 1: V[t+1] = V[t] + I[t]（积分，复用积分器）
  Step 2: 如果 V[t+1] >= threshold → 输出脉冲1，V在下一时钟沿复位
          否则 → 输出脉冲0，V保持不变
```

#### 4.3.2 电路实现（在积分器基础上增加）

```
                    ┌───────────┐
    ┌──────────────→│ 比较器     │
    │               │ A  │ B      │
    │               │ V  threshold│
    │               └─────┬─────┘
    │                     │ A >= B ?
    │                     ▼
    │               ┌────────────┐
    │               │ 输出脉冲    │
    │               │ (spike_out)│
    │               └──────┬─────┘
    │                      │
    │                      ▼
    │                 ┌───────────────┐
    │                 │ 复位控制       │
    │                 │ (spike_out = 1 │
    │                 │  时触发)       │
    │                 └───────┬───────┘
    │                         │
    │                         ▼
    │                    ┌────────────┐
    └────────────────────┤ 寄存器CLR  │
                         │ (清零V)    │
                         └────────────┘
```

#### 4.3.3 完整电路信号流

```
input_spike ──→ MUX ──→ 加法器 ──→ 寄存器(V) ──→ 比较器 ──→ spike_out
                  ↑       ↑            │           ↑
                  │       │            │        threshold
                  └─weight┘            │
                                       │
                              ┌────────┘
                              ▼
                           复位控制
                           (spike_out=1时清零)
                    ┌───────────┘
                    ▼
                寄存器CLR引脚
```

#### 4.3.4 时序控制（关键难点）

```
每个时钟周期上升沿触发：

在 10MHz (100ns) 时钟下，单周期内组合逻辑传播路径：

  IF 神经元关键路径:
    ① CLK上升沿：寄存器输出 V_old
    ② 组合逻辑路径:
       MUX(传输门: ~0.1-0.3ns) → 加法器(4位CLA: ~0.4-1.0ns@65nm, ~1-2ns@90nm)
       → 比较器(~0.3-0.8ns) → spike_out / V_new 稳定
       单输入 4-bit 演示总延迟约 1-4ns@65nm（3-8ns@90nm）
    ③ 下一个 CLK上升沿：采样 V_new 或清零

  ANN-MAC 关键路径:
    ① CLK上升沿：寄存器输出累加值
    ② 组合逻辑路径:
       AND门 → 阵列乘法器(4-6级FA进位) → CLA(4-6级门)
       → 寄存器D输入稳定
       总延迟约 2-6ns@65nm（5-12ns@90nm）
    ③ 下一个 CLK上升沿：采样新的累加值

  Clock Cycle 1:
    ① CLK上升沿：寄存器输出 V_old
    ② 组合逻辑：MUX选择(weight或0) → 加法器计算 V_new = V_old + I
    ③ 组合逻辑：比较器判断 V_new >= threshold？
       - 如果 V_new >= threshold: spike_out=1，寄存器CLR信号=1
       - 否则: spike_out=0，寄存器CLR信号=0
    (下一个CLK上升沿：如果CLR有效，寄存器清零；否则寄存V_new)
```

**关键**：加法器和比较器是组合逻辑，在同一个时钟周期内完成计算和比较。复位信号经同步化 DFF 后在下一个时钟沿生效，因此触发当周期 V 保持为 V_new，下一周期才清零。

**注意**：以上延迟为基于典型门延迟的预估值（参考 TSMC 65nm/gpdk90 典型 INV 延迟 ~10-20ps，NAND2 ~15-25ps，XOR2 ~30-50ps）。实际值须在 Cadence Spectre 中实测 tpLH/tpHL 后确认。在首次功能验证中，10MHz (100ns) 提供了充足裕度（约 10-50 倍），确保所有组合路径在时钟沿之前稳定。

#### 4.3.5 真值表验证

| 时钟 | input | weight | V_old | I | V_new | threshold | spike_out | V_next |
|---|---|---|---|---|---|---|---|---|
| 1 | 1 | 5 | 0 | 5 | 5 | 10 | 0 | 5 |
| 2 | 1 | 5 | 5 | 5 | 10 | 10 | 1 | **10**（本周期保持，因同步复位下一周期生效） |
| 3 | 0 | 5 | 10 | 0 | 10 | 10 | 1 | **0**（上周期采样的 spike=1 生效清零） |
| 4 | 1 | 5 | 0 | 5 | 5 | 10 | 0 | 5 |
| 5 | 1 | 5 | 5 | 5 | 10 | 10 | 1 | **10**（本周期保持） |

**验证目标**：
- V 累积到（或达到）阈值后触发脉冲
- 触发后下一个时钟沿复位
- 复位后重新开始累积

**时序注意事项**：比较器输出到寄存器复位之间是异步路径——比较器在组合逻辑路径中完成判断，而寄存器在时钟沿采样。Cadence 实现时在复位信号上增加一个**同步化 DFF**，将异步比较结果对齐到下一个时钟上升沿，避免亚稳态。具体做法：
```
spike_out → DFF(D输入) → CLK上升沿 → DFF(Q输出) → 寄存器CLR引脚
```
这样可以确保复位信号与寄存器时钟严格同步。

#### 4.3.6 比较器门级实现（4-bit `A >= B`）

本课题触发条件为 `V >= threshold`，比较器从最高位开始逐位比较：

- 若 `Ai > Bi`，则 `A > B`
- 若 `Ai < Bi`，则 `A < B`
- 若相等，则继续比较下一位
- 全部相等则 `A = B`，满足 `A >= B`

定义每位的三个辅助信号：

```
Gi = Ai · ~Bi          (Ai 大于 Bi)
Li = ~Ai · Bi          (Ai 小于 Bi)
Ei = ~(Ai ⊕ Bi)        (Ai 等于 Bi)
```

4-bit 比较结果：

```
A_gt_B = G3 + E3·G2 + E3·E2·G1 + E3·E2·E1·G0
A_eq_B = E3·E2·E1·E0
A_ge_B = A_gt_B + A_eq_B      // 即本课题使用的 spike_out
```

晶体管数估算：4-bit 数值比较器约 150-220 个晶体管。

### 4.4 Cadence搭建步骤

```
Level 1: 积分器（从已有元件搭建）
  ├── MUX：传输门实现（每个 weight bit 一个 2选1 MUX；N-bit 权重共 N 组）
  ├── 加法器：使用ANN-MAC中已搭的半加器+全加器，位宽需覆盖无溢出范围
  ├── 寄存器：使用**带同步复位CLR引脚的D触发器**（上升沿触发复位）
  └── 时钟信号：从testbench提供10MHz方波

Level 2: IF神经元（在积分器上增加）
  ├── 比较器：4位数值比较器，实现 A >= B
  │   └── 逐位比较：A[3] vs B[3] → A[2] vs B[2] → ...
  ├── 复位逻辑：spike_out 经同步 DFF 后连寄存器 CLR
  └── 阈值寄存器：外部输入到比较器B端
```

### 4.5.1 时钟频率选择依据

**选择 10MHz（周期 100ns）的理由**：

| 因素 | 值 | 说明 |
|---|---|---|
| SNN-IF 组合路径(MUX→加法器→比较器) | ~1-4ns@65nm / ~3-8ns@90nm | 加法器约 3-5 级门 + 比较器约 2-4 级门（预估值，以实测为准） |
| ANN-MAC 组合路径(AND→阵列乘法器→CLA→寄存器) | ~2-6ns@65nm / ~5-12ns@90nm | 乘法器约 4-6 级进位 + CLA 约 4-6 级门 + 寄存器 setup（预估值，以实测为准） |
| 寄存器建立时间 | ~0.05-0.2ns@65nm / ~0.1-0.5ns@90nm | DFF setup time（典型值） |
| ANN-MAC 关键路径总延迟 | ~2-6ns@65nm / ~5-12ns@90nm | << 100ns 时钟周期 |
| SNN-IF 关键路径总延迟 | ~1-4ns@65nm / ~3-8ns@90nm | << 100ns 时钟周期 |
| **安全裕度** | **约 10-50 倍** | 两种电路在 10MHz 下均有充足时序裕度 |

- **ANN-MAC 关键路径**：AND 门 → 阵列乘法器（4-6 级 FA 进位传播）→ CLA（4-6 级门）→ 寄存器 setup。该路径经过乘法器和加法器两级组合逻辑，延迟大于 IF 神经元的 MUX→加法器→比较器路径。
- 10MHz 下两种电路的时序裕度均充足，适合首次功能验证
- 实际数字电路可运行在更高频率(50-100MHz)，但本课题优先验证功能正确性
- **对比公平性**：ANN-MAC 和 SNN-IF 使用**相同的 10MHz 时钟**，功耗对比使用相同条件
- Cadence 仿真设置：`vpulse` 信号源，周期 `100ns`，占空比 `50%`
- **注意**：以上延迟数值为基于典型门延迟的预估值。实际延迟须在 Cadence Spectre 中通过瞬态仿真测量 tpLH/tpHL 确认。如无法精确估计，建议标注"预估值，以 Cadence 仿真实测为准"。

#### 5.2.1 单神经元到全层的功耗外推

Cadence 实测的是**单个 IF 神经元**的功耗。全层功耗通过以下公式外推：

```
隐藏层(300神经元, 每个接784输入)估算功耗:
  每神经元: P_conn = 784 × P_MUX + P_adder_tree + P_register + P_comparator
  全层动态功耗 ≈ 300 × P_conn × firing_rate × T × P_unit_cycle

简化外推（以单神经元实测为基准）:
  全层功耗 ≈ P_if_single × 300 × T × firing_rate

ANN 功耗（对比基准）:
  单张图片: 238,200次MAC操作
  全层功耗 ≈ P_mac_single × 238,200 / 并行度
  （公平对比假设并行度=16，串行假设下 SNN 优势更明显）
```

**外推假定需在答辩中声明**：
- 线性外推忽略布线负载和时钟树功耗（实际占比 15-30%）
- 假定了所有连接功率均等（实际不同位的权重路径延迟不同）
- 上述假定使外推值偏保守（实际功耗更高），SNN 的优势在保守估计下仍可验证

## 第六章 准确率-功耗trade-off拟合

### 6.1 方法

以 ANN 为基准（准确率~95%，功耗由 Cadence 实测 MAC 单元功耗外推得到），通过改变 SNN 的 **(时间步 T, 阈值 Vth)** 组合收集 3-4 个数据点，在同一坐标系中拟合准确率-功耗 trade-off 曲线。

**变量说明**：
- **时间步 T**：每张图片的仿真时间步数。T 越大，泊松编码的信息越充分→准确率越高；但总功耗 = T × 每步功耗，T 等比例增加总推理功耗
- **阈值 Vth**：IF 神经元的触发阈值。Vth 越小，越容易触发→脉冲活动更频繁→功耗可能增加，同时影响准确率
- **(T, Vth) 组合**：两个变量交叉变化可产生多样化的 (准确率, 功耗) 数据点

**功耗外推方法**：
1. Cadence 实测单 IF 神经元在 10MHz 下的**单位周期动态功耗** P_if_single (mW)
2. 单张 SNN 推理总功耗估算：
   ```
   P_total = P_if_single × 300 × T × firing_rate_layer1
           + P_if_single × 10 × T × firing_rate_layer2
   ```
3. ANN 对比基准（以单 MAC 单元实测功耗 P_mac 外推）：
   ```
   P_ANN = P_mac × 238,200 / 并行度(假设=16)
   ```
   并行度假定在答辩中明确声明；保守/串行假设下 ANN 功耗更高，SNN 优势更大

### 6.2 数据收集计划

|---|---|---|---|---|
| 基线 | ANN, ReLU, 784-300-10 | ~95% | — | P_ANN = P_mac × 238,200 / 16 |
| 数据点1 | SNN, T=100, Vth=1.0 | 见 `snn_tradeoff_data_based.csv` | 从仿真统计 | P_if_single × 300 × 100 × rate |
| 数据点2 | SNN, T=50, Vth=1.0 | 见 `snn_tradeoff_data_based.csv` | 从仿真统计 | P_if_single × 300 × 50 × rate |

### 8.1 关键风险

| 风险 | 概率 | 影响 | 缓解措施 |

| SNN准确率过低 | 中 | trade-off曲线数据点不够 | (1) 切换到data-based归一化；(2) 扫描阈值theta=0.5~2.0；(3) 增加T到100/200；(4) 多组(T,theta)组合总有一组有意义 |
| IF神经元时序不通过 | 低 | 电路不能正确触发 | 从积分器退一步验证；检查CLK与CLR的时序关系（确认同步复位DFF正常工作） |
| Cadence仿真不收敛 | 低 | 无法提取精确功耗 | 增加仿真时间；检查激励信号是否合理；考虑降低仿真精度要求(tran step) |
| ANN训练无法达到95% | 低 | 基线不成立 | 增加epoch到50；调低lr到0.005；确认Kaiming初始化正确 |
