## 一、研究背景与问题定义

### 1.1 课题主题定位

本课题围绕"类脑芯片助力人工智能"这一主题，研究两种神经网络计算范式在硬件实现层面的差异：

| 维度 | ANN（传统人工神经网络） | SNN（脉冲神经网络） |
|---|---|---|
| 生物合理性 | 抽象简化，不模拟脉冲 | 模拟生物脉冲发射机制 |
| 信息表示 | 连续数值（float32） | 离散脉冲（0/1 spike） |
| 核心运算 | MAC（乘法+加法） | 脉冲累加+阈值触发（无需乘法） |
| 计算模式 | 持续计算（所有神经元都运算） | 事件驱动（仅脉冲触发时运算） |
| 功耗特性 | 始终高功耗 | 脉冲稀疏→低功耗 |
| 业界成熟度 | 成熟（GPU/TPU都是ANN） | 前沿研究（Loihi/天机芯片） |

### 1.2 研究问题

**核心问题**：对于同一任务（MNIST手写数字识别），SNN的LIF神经元电路相比ANN的MAC单元，在硬件开销（延迟/功耗/面积）上有什么差异？这种差异是否足以支撑"SNN更适合类脑芯片"的判断？

### 1.3 为什么要做这个对比

- 课题组单元1已教SNN/LIF概念（单元1 Slide 25-27），但往届无人实现
- 课题组主题是"类脑芯片"，SNN是最类脑的计算模型，不做SNN=没扣题
- 现有对比研究多在软件层面，本课题补充硬件电路层面的量化对比

### 1.4 双层定位

| 层次 | 内容 | 怎么满足 |
|---|---|---|
| 课题组答辩 | 基于已学数字电路（加法器/寄存器/比较器）+ SNN概念已教，搭建LIF神经元 | 用已学知识做新东西，能讲清原理 |
| 比赛参赛 | SNN硬件是前沿研究方向，真正有创新性 | 不是业界标准，是研究热点 |

### 1.5 LIF分层实现策略：每层都有独立汇报价值（关键）

**核心思路**：SNN-LIF电路不是一次性做出来的，而是分三层逐步实现。每一层都是一个完整可工作的电路，都有独立的汇报价值。IF神经元（v2）本身就可以和ANN-MAC做有意义的对比。

**研究顺序**：

```
Step 1: ANN软件训练 + ANN-MAC电路 ← 已学，快速完成
    ↓
Step 2: SNN软件（ANN-to-SNN转换） ← 纯代码，AI辅助
    ↓
Step 3: LIF v1 积分器（加法器+寄存器） ← 验证膜电位累积功能
    ↓
Step 4: LIF v2 IF神经元（积分器+比较器） ← 可独立对比的关键节点
    ↓
Step 5: IF vs MAC 对比分析 ← v2完成即可做对比
    ↓
Step 6: LIF v3 完整版（+泄漏+复位） ← 有时间再升级
```

**LIF三层递进**：

| 版本 | 功能 | 对应SNN模型 | 电路实现 | 独立汇报价值 |
|---|---|---|---|---|
| v1 积分器 | V += 输入 | 膜电位累积 | 加法器+寄存器 | 展示SNN最基本的"累积"原理，验证数字电路实现类脑计算的可行性 |
| v2 IF神经元 | 积分+触发 | **IF脉冲神经元** | 加法器+寄存器+比较器 | **核心输出**——独立可用的SNN计算单元，已完成与MAC的硬件对比 |
| v3 完整LIF | 积分+泄漏+触发+复位 | LIF脉冲神经元 | 全功能电路 | 更贴近生物神经元动力学，但对比结论与v2基本一致 |

**v2（IF神经元）的独立价值**：
- IF神经元（Integrate-and-Fire）本身就是SNN领域广泛使用的简化模型，许多神经形态芯片（如Loihi的前身）用的就是IF而非完整LIF
- "无需乘法器"和"事件驱动"两个核心优势在IF阶段就已经成立
- IF电路完成后即可与ANN-MAC做完整的硬件对比（延迟/功耗/晶体管数），对比结论和完整LIF基本一致

**v3（完整LIF）的地位**：
- 在IF基础上增加了泄漏和复位，更贴近生物神经元动力学
- 是锦上添花不是必须——对比结论在v2阶段已经确定
- 有时间就做，没时间就用v2答辩

#### 4.1.2 ANN-to-SNN转换（仅完整方案，Week 5启动）

**采用ANN-to-SNN转换方法**（工业界标准，不从头训练SNN）：

```
步骤1: 训练好的Float32 ANN权重直接复用
步骤2: 对权重做归一化（因为LIF和ReLU的输出范围不同）
步骤3: ReLU神经元 → LIF神经元替换
       - ANN: y = ReLU(W·x + b)
       - SNN: 膜电位V累积输入，V>阈值时发脉冲，V复位
步骤4: 输入图片编码为脉冲序列（泊松编码/Poisson Encoding）
步骤5: 仿真N个时间步，统计输出层脉冲数最多的神经元=识别结果
```

**关键技术点**（需自学+AI辅助）：
1. **泊松编码**：把28×28像素值转为脉冲序列
2. **LIF动力学公式**：τ·dV/dt = -V + R·I(t)，离散化后V[t+1] = V[t]·decay + I[t]
3. **权重归一化**：ANN权重缩放到LIF能正常工作的范围
4. **时间步数选择**：典型N=20-100步

**难度：⭐⭐⭐（AI能写代码，原理要自己理解）**
**风险**：准确率可能85-90%，即使不达标也不影响兜底汇报（两个电路对比已完成）

#### 4.1.3 脉冲稀疏性分析（可选加分）

统计SNN仿真过程中平均每个神经元的脉冲发放率（firing rate）。脉冲越稀疏，事件驱动优势越大。

**难度：⭐⭐**

#### 4.2.2 SNN-LIF神经元电路（核心创新，兜底+完整共用）

**LIF神经元数学模型**（已教，单元1 Slide 27）：
- Leaky: V随时间衰减
- Integrate: V累积输入
- Fire: V>阈值时发脉冲

**数字电路实现方案**：

| LIF功能 | 数字电路实现 | 原理 | 已学依据 |
|---|---|---|---|
| **积分(Integrate)** | 加法器+寄存器 | 每个时钟周期，寄存器值 = 寄存器旧值 + 输入×权重 | 加法器已学，寄存器已学 |
| **泄漏(Leaky)** | 移位操作（右移1位=除以2） | 每个周期V右移1位，模拟衰减 | 移位是逻辑电路基础 |
| **触发(Fire)** | 比较器（V > 阈值） | 比较器输出1=发脉冲 | 比较器=逻辑门组合，已学 |
| **复位(Reset)** | 寄存器清零 | 触发后寄存器置0 | 寄存器控制已学 |
| **脉冲×权重** | MUX选择 | 有脉冲=加权重，无脉冲=加0 | MUX=逻辑门组合，已学 |

**电路结构示意**：

```
        ┌─────────────────────────────────────────┐
        │            SNN-LIF 神经元电路             │
        │                                          │
输入脉冲├──→MUX──→加法器──→寄存器(V)──→比较器──→输出脉冲
  │     ↑   ↑              │           │          │
  │     │   └──权重W        │           │阈值      │
  │     │                   │           │          │
  │     │      ┌────────────┘           │          │
  │     │      ▼ (右移=泄漏)             │          │
  │     │   移位器←──────────────────────┘          │
  │     │                                         │
  │     └───────────────────────────(触发时清零)──┘
  │                  ↑
  └──MUX控制─────────┘
```

**难点**：模块都学过，但**时序控制**（什么时候加、什么时候比、什么时候清零）是新东西，AI可辅助设计状态机

**难度：⭐⭐（模块已学，组合+时序是新东西）**

## 十一、答辩核心知识点

答辩时必须能讲清的7个知识点：

1. **SNN vs ANN的本质区别**（脉冲vs数值，事件驱动vs持续计算）
2. **IF神经元工作原理**（Integrate积分→Fire触发，两段式工作）
3. **LIF与IF的区别**（完整LIF多了泄漏和复位，更贴近生物神经元）
4. **数字电路实现的模块拆解**（积分=加法器+寄存器；触发=比较器；泄漏=移位器；复位=清零）
5. **为什么SNN不需要乘法器**（脉冲是0/1，有脉冲=加权重，无脉冲=加0，MUX代替乘法）
6. **为什么SNN理论上更省电**（事件驱动→脉冲稀疏时运算量小于ANN连续计算）
7. **IF阶段即可对比的原因**（"无需乘法器"和"事件驱动"两个核心差异在IF阶段已成立，v2以后的增量主要是生物真实性而非核心优势）

**答辩叙事（推荐）**：

> "我从ANN的MAC乘加单元出发，逐步实现了SNN的脉冲计算单元。
> 
> 第一步做了积分器（v1），验证膜电位累积原理——用加法器和寄存器模拟了生物神经元接收输入后电位逐步上升的过程。
> 
> 第二步加上阈值比较器（v2），实现了IF脉冲神经元——这是SNN最基本的计算单元。到这一步，我已经可以用数字电路模拟脉冲的积分-触发机制了。
> 
> 第三步在v2基础上加了泄漏和复位（v3），实现了完整的LIF神经元，更贴近生物神经元的动力学特性。
> 
> 在v2完成后，我就用IF神经元和ANN的MAC单元做了硬件对比。结果是：SNN-IF不需要乘法器、结构更简单，即使只计基本功耗，事件驱动特性在大规模网络中也有本质优势。这就是SNN被研究界认为更适合类脑计算的原因。"

**可能的尖锐问题及应对**：
- Q: "你的SNN和Loihi芯片有什么本质区别？"
  - A: Loihi是模拟/混合信号神经形态芯片，本课题用数字电路实现LIF，验证的是"数字电路能否实现类脑计算"这一基础问题，是面向教学和原理验证的简化实现
- Q: "数字电路SNN相比模拟电路SNN有什么局限？"
  - A: 数字电路精度受位宽限制，功耗比模拟电路高，但设计灵活、可编程性强，适合原理验证和学习
