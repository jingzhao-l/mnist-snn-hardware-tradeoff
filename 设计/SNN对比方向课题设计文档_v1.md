## 一、研究背景与问题定义

### 1.1 课题主题定位

本课题围绕"类脑芯片助力人工智能"这一主题，研究两种神经网络计算范式在硬件实现层面的差异：

| 维度 | ANN（传统人工神经网络） | SNN（脉冲神经网络） |
|---|---|---|
| 生物合理性 | 抽象简化，不模拟脉冲 | 模拟生物脉冲发射机制 |
| 信息表示 | 连续数值（float32） | 离散脉冲（0/1 spike） |
| 核心运算 | MAC（乘法+加法） | 脉冲累加+阈值触发（无需乘法） |
| 计算模式 | 持续计算（所有神经元都运算） | 事件驱动（仅脉冲触发时运算） |
| 功耗特性 | 始终高功耗 | 脉冲稀疏→低功耗 |
| 业界成熟度 | 成熟（GPU/TPU都是ANN） | 前沿研究（Loihi/天机芯片） |

### 1.2 研究问题

**核心问题**：对于同一任务（MNIST手写数字识别），SNN的LIF神经元电路相比ANN的MAC单元，在硬件开销（延迟/功耗/面积）上有什么差异？这种差异是否足以支撑"SNN更适合类脑芯片"的判断？

### 1.3 为什么要做这个对比

- 课题组单元1已教SNN/LIF概念（单元1 Slide 25-27），但往届无人实现
- 课题组主题是"类脑芯片"，SNN是最类脑的计算模型，不做SNN=没扣题
- 现有对比研究多在软件层面，本课题补充硬件电路层面的量化对比

### 1.4 双层定位

| 层次 | 内容 | 怎么满足 |
|---|---|---|
| 课题组答辩 | 基于已学数字电路（加法器/寄存器/比较器）+ SNN概念已教，搭建LIF神经元 | 用已学知识做新东西，能讲清原理 |
| 比赛参赛 | SNN硬件是前沿研究方向，真正有创新性 | 不是业界标准，是研究热点 |

**难度：⭐（已学复用）**

#### 4.1.2 SNN实现（核心创新1）

**采用ANN-to-SNN转换方法**（工业界标准，不从头训练SNN）：

```
步骤1: 训练好的ANN权重直接复用
步骤2: 对权重做归一化（因为LIF和ReLU的输出范围不同）
步骤3: ReLU神经元 → LIF神经元替换
       - ANN: y = ReLU(W·x + b)
       - SNN: 膜电位V累积输入，V>阈值时发脉冲，V复位
步骤4: 输入图片编码为脉冲序列（泊松编码/Poisson Encoding）
步骤5: 仿真N个时间步，统计输出层脉冲数最多的神经元=识别结果
```

**关键技术点**（需自学+AI辅助）：
1. **泊松编码**：把28×28像素值转为脉冲序列，像素值越大脉冲发放概率越高
2. **LIF动力学公式**：τ·dV/dt = -V + R·I(t)，离散化后V[t+1] = V[t]·decay + I[t]
3. **权重归一化**：ANN权重缩放到LIF能正常工作的范围
4. **时间步数选择**：典型N=20-100步，越多越准但越慢

**难度：⭐⭐⭐（AI能写代码，原理要自己理解）**
**风险**：准确率可能85-90%，不如ANN，但对比分析依然成立

#### 4.1.3 脉冲稀疏性分析

统计SNN仿真过程中：
- 平均每个神经元的脉冲发放率（firing rate）
- 每个时间步有多少神经元在发放
- 脉冲稀疏性 = (实际脉冲数) / (最大可能脉冲数)

**意义**：脉冲越稀疏，说明SNN的事件驱动优势越大，硬件功耗越低

**难度：⭐⭐（统计计算，简单）**

#### 4.2.2 SNN-LIF神经元电路（核心创新2）

**LIF神经元数学模型**（已教，单元1 Slide 27）：
- Leaky: V随时间衰减
- Integrate: V累积输入
- Fire: V>阈值时发脉冲

**数字电路实现方案**：

| LIF功能 | 数字电路实现 | 原理 | 已学依据 |
|---|---|---|---|
| **积分(Integrate)** | 加法器+寄存器 | 每个时钟周期，寄存器值 = 寄存器旧值 + 输入×权重 | 加法器已学，寄存器已学 |
| **泄漏(Leaky)** | 移位操作（右移1位=除以2） | 每个周期V右移1位，模拟衰减 | 移位是逻辑电路基础 |
| **触发(Fire)** | 比较器（V > 阈值） | 比较器输出1=发脉冲 | 比较器=逻辑门组合，已学 |
| **复位(Reset)** | 寄存器清零 | 触发后寄存器置0 | 寄存器控制已学 |
| **脉冲×权重** | MUX选择 | 有脉冲=加权重，无脉冲=加0 | MUX=逻辑门组合，已学 |

**电路结构示意**：

```
        ┌─────────────────────────────────────────┐
        │            SNN-LIF 神经元电路             │
        │                                          │
输入脉冲├──→MUX──→加法器──→寄存器(V)──→比较器──→输出脉冲
  │     ↑   ↑              │           │          │
  │     │   └──权重W        │           │阈值      │
  │     │                   │           │          │
  │     │      ┌────────────┘           │          │
  │     │      ▼ (右移=泄漏)             │          │
  │     │   移位器←──────────────────────┘          │
  │     │                                         │
  │     └───────────────────────────(触发时清零)──┘
  │                  ↑
  └──MUX控制─────────┘
```

**难点**：模块都学过，但**时序控制**（什么时候加、什么时候比、什么时候清零）是新东西，AI可辅助设计状态机

**难度：⭐⭐（模块已学，组合+时序是新东西）**

#### 4.3.3 脉冲稀疏性对功耗的影响

SNN的事件驱动意味着"没脉冲时不运算"，理论上功耗远低于ANN。但实际要乘以脉冲稀疏性：
- 如果脉冲稀疏性=10%，SNN实际运算量≈ANN×10%→功耗大幅降低
- 如果脉冲稀疏性=70%，SNN优势不明显

**创新点**：用实际仿真的脉冲稀疏性数据，定量分析SNN的功耗优势

- Q: "你的SNN和Loihi芯片有什么本质区别？"
  - A: Loihi是模拟/混合信号神经形态芯片，本课题用数字电路实现LIF，验证的是"数字电路能否实现类脑计算"这一基础问题，是面向教学和原理验证的简化实现
- Q: "数字电路SNN相比模拟电路SNN有什么局限？"
  - A: 数字电路精度受位宽限制，功耗比模拟电路高，但设计灵活、可编程性强，适合原理验证和学习
