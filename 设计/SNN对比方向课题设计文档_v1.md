## 一、研究背景与问题定义

### 1.1 课题主题定位

本课题围绕"类脑芯片助力人工智能"这一主题，研究两种神经网络计算范式在硬件实现层面的差异：

| 维度 | ANN（传统人工神经网络） | SNN（脉冲神经网络） |
|---|---|---|
| 生物合理性 | 抽象简化，不模拟脉冲 | 模拟生物脉冲发射机制 |
| 信息表示 | 连续数值（float32） | 离散脉冲（0/1 spike） |
| 核心运算 | MAC（乘法+加法） | 脉冲累加+阈值触发（无需乘法） |
| 计算模式 | 持续计算（所有神经元都运算） | 事件驱动（仅脉冲触发时运算） |
| 功耗特性 | 始终高功耗 | 脉冲稀疏→低功耗 |
| 业界成熟度 | 成熟（GPU/TPU都是ANN） | 前沿研究（Loihi/天机芯片） |

### 1.2 研究问题

**核心问题**："SNN相比ANN更省电"是一个被广泛接受的定性结论，但**省多少电、换多少准确率**这一量化关系缺乏实验数据支撑。本课题旨在通过实际的电路仿真数据，拟合出SNN的"准确率-功耗"定量trade-off关系曲线。

### 1.3 为什么要做这个课题

- 课题组单元1已教SNN/IF/LIF概念（单元1 Slide 25-27），但往届无人实现
- 课题组主题是"类脑芯片"，SNN是最类脑的计算模型
- "SNN更省电"是课堂结论，但"省多少电、损失多少准确率"的定量关系课堂没有给出——这正是本课题要填补的空白

### 1.4 课题定位

| 层次 | 内容 |
|---|---|
| 课题组答辩 | 基于已学数字电路（加法器/寄存器/比较器）+ SNN概念已教，搭建IF神经元并与ANN-MAC做对比 |
| 最终结论 | 用实验数据拟合"准确率-功耗"定量trade-off曲线，把验证功耗优势作为必要步骤而非最终结论 |

### 1.5 研究流程

```
Step 1: ANN-MLP基线
    ├── 软件：训练MLP 784-300-10（ReLU, numpy手写），MNIST准确率≥95%
    └── 硬件：搭4×4阵列乘法器+4位CLA加法器（ANN-MAC），测延迟/功耗/晶体管数
    ↓
Step 2: ANN-to-SNN转换（软件）
    ├── 前提：ANN须使用ReLU（已满足）、输入[0,1]归一化（已满足）、无BN/Dropout
    ├── 权重复用+ReLU→IF替换+泊松编码
    └── 时间步仿真，MNIST准确率≥85%
    ↓
Step 3: SNN-IF神经元电路（硬件，递进实现）
    ├── 第一阶段：积分器（加法器+寄存器），验证膜电位累积
    └── 第二阶段：IF脉冲神经元（积分器+比较器），实现积分-触发机制
    ↓
Step 4: 对比分析（必要步骤）
    ├── ANN-MAC vs SNN-IF：晶体管数/延迟/功耗/是否需乘法器/是否事件驱动
    └── 验证SNN在硬件层面的功耗优势
    ↓
Step 5: 准确率-功耗trade-off拟合（最终结论）
    └── 以ANN为基准，拟合SNN的准确率下降与功耗节省之间的量化关系曲线
```

### 1.6 IF神经元递进实现策略

| 阶段 | 功能 | 电路实现 | 独立汇报价值 |
|---|---|---|---|
| 第一阶段积分器 | V += 输入 | 加法器+寄存器 | 展示膜电位累积原理，验证数字电路实现类脑计算的基础功能 |
| 第二阶段IF神经元 | 积分+触发 | 积分器+比较器 | **核心产出**——独立可用的SNN计算单元，完成与MAC的硬件对比 |

IF神经元（Integrate-and-Fire）本身就是SNN领域广泛使用的简化模型。"无需乘法器"和"事件驱动"两个核心优势在IF阶段就已经成立，IF电路完成后即可进入对比分析和trade-off拟合阶段。

**难度：⭐⭐（手写反向传播，但逻辑清晰）**

#### 3.1.2 ANN-to-SNN转换

**采用ANN-to-SNN转换方法**（工业界标准，不从头训练SNN）：

```
步骤1: 训练好的Float32 ANN权重直接复用
步骤2: 对权重做归一化（因为IF和ReLU的输出范围不同）
步骤3: ReLU神经元 → IF神经元替换（仅隐藏层）
       - ANN: y = ReLU(W·x + b)
       - SNN: 膜电位V累积输入，V>阈值时发脉冲，V复位
       - **注意**：输出层不替换——SNN输出层仍保持浮点计算（统计脉冲数→取最大）
步骤4: 输入图片编码为脉冲序列（泊松编码）
步骤5: 仿真N个时间步，统计输出层脉冲数最多的神经元=识别结果
```

**关键技术点**（需自学）：
1. **泊松编码**：把28×28像素值转为脉冲序列
2. **IF动力学公式**：V[t+1] = V[t] + I[t]；当V>阈值时输出脉冲并复位
3. **权重归一化**（两种方法，优先方法1）：
   - **方法1 (max_norm)**：每层权重除以该层最大绝对值，简单快速
   - **方法2 (data-based 99.9%分位)【备选】**：用训练集跑ANN前向传播，记录每层激活值的99.9%分位数作为缩放因子。当方法1导致SNN准确率<85%时启用，对异常激活值更鲁棒
4. **时间步数选择**：典型N=20-100步

**难度：⭐⭐⭐（代码量大，但逻辑清晰）**
**风险**：准确率可能85-90%，但即使不达标，对比分析中不同准确率数据点本身就是trade-off曲线的一部分

#### 3.1.3 脉冲稀疏性统计

统计SNN仿真过程中平均每个神经元的脉冲发放率（firing rate），用于定量分析事件驱动对功耗的影响。

**难度：⭐⭐**

#### 3.2.2 SNN-IF脉冲神经元电路（核心创新）

**IF神经元数学模型**：
- Integrate（积分）：V[t+1] = V[t] + I[t]
- Fire（触发）：当V > 阈值时输出脉冲，V复位

**数字电路实现方案**：

| IF功能 | 数字电路实现 | 原理 | 已学依据 |
|---|---|---|---|
| **积分(Integrate)** | 加法器+寄存器 | 每个时钟周期，寄存器值 = 寄存器旧值 + 输入×权重 | 加法器已学，寄存器已学 |
| **触发(Fire)** | 比较器（V > 阈值） | 比较器输出1=发脉冲 | 比较器=逻辑门组合，已学 |
| **复位(Reset)** | 寄存器清零 | 触发后寄存器置0 | 寄存器控制已学 |
| **脉冲×权重** | MUX选择 | 有脉冲=加权重，无脉冲=加0 | MUX=逻辑门组合，已学 |

**电路结构示意**：

```
        ┌──────────────────────────────────┐
        │         SNN-IF 神经元电路         │
        │                                   │
输入脉冲├──→MUX──→加法器──→寄存器(V)──→比较器──→输出脉冲
  │     ↑   ↑              │           │
  │     │   └──权重W        │           │阈值
  │     │                   │           │
  │     └───────────────────┘────(触发时清零)
```

**递进实现**：
- 第一阶段（积分器）：只搭加法器+寄存器，验证V能正确累积输入
- 第二阶段（IF神经元）：加上比较器+阈值+复位，完成完整的积分-触发机制

**验证范围说明**：本课题在 Cadence 上验证**单神经元级别的 IF 积分-触发原理**。MUX+加法器+寄存器+比较器实现的是单个 IF 神经元的基本计算单元。实际 SNN 隐藏层包含 300 个神经元，每个接收 784 路输入脉冲——完整层的多输入连接是规模扩展问题，核心原理与单神经元验证完全一致。本课题的电路设计聚焦于"证明 IF 机制在数字电路上的可行性和硬件开销"，完整层的连接拓扑留作展望。

**难点**：时序控制（什么时候加、什么时候比、什么时候清零）是新东西，但模块本身都已学过

**难度：⭐⭐（模块已学，组合+时序是新内容）**

#### 3.3.2 准确率-功耗trade-off定量拟合（最终结论）

**问题**：SNN省电但准确率下降，具体省多少电换多少准确率？

**方法**：以ANN为基准（准确率~95%，功耗100%），通过改变SNN的**(时间步T, 阈值Vth)**组合获得3-4个数据点，在同一坐标系中拟合曲线。

**变量解释**：
- **T（时间步数）**：T越大→泊松编码信息越充分→准确率越高，但总功耗 = T × 每步功耗
- **Vth（触发阈值）**：Vth越小→越容易触发→脉冲活动更频繁→影响功耗和准确率
- **(T, Vth) 组合**：两个参数交叉变化提供多样化的数据点

**功耗外推方法**：
1. Cadence 实测单 IF 神经元在 10MHz 下的单位周期动态功耗
2. 全层功耗 = 单神经元功耗 × 神经元数(300) × 时间步数(T) × 脉冲稀疏率
3. ANN 基准功耗 = 单 MAC 单元功耗 × 23,700 次 / 并行度(假设=16)

| 数据点 | 条件 | 准确率 | 层估算功耗 | 功耗节省率 |
|---|---|---|---|---|
| 1(基线) | ANN | ~95% | P_ANN | 0% |
| 2 | SNN, T=100, Vth=1.0 | ~88% | P_SNN = P_if × 300 × 100 × 稀疏率 | ? |
| 3 | SNN, T=50, Vth=1.0 | ~86% | 同上 | ? |
| 4 | SNN, T=30, Vth=1.0 | ~84% | 同上 | ? |

**最终结论**：给出"每降低1%准确率，大约能省X%功耗"的定量关系。功耗外推的线性假定已在答辩材料中明确声明。

**为什么这是最终结论**：单纯证明"SNN更省电"是课堂已知结论；而"省多少电换多少准确率"的量化关系是课堂没有的，是本课题区别于往届的核心贡献。

## 九、答辩核心知识点

答辩时必须能讲清的7个知识点：

1. **SNN vs ANN的本质区别**（脉冲vs数值，事件驱动vs持续计算）
2. **IF神经元工作原理**（Integrate积分→Fire触发，两段式工作）
3. **数字电路实现的模块拆解**（积分=加法器+寄存器；触发=比较器；复位=清零）
4. **为什么SNN不需要乘法器**（脉冲是0/1，有脉冲=加权重，无脉冲=加0，MUX代替乘法）
5. **为什么SNN理论上更省电**（事件驱动→脉冲稀疏时运算量小于ANN连续计算）
6. **对比分析的结论**（验证了SNN的硬件功耗优势，这是必要步骤）
7. **trade-off曲线的意义**（"每降低1%准确率，大约能省X%功耗"——这是本课题的最终结论，课堂没有的量化关系）

**答辩叙事**：

> "我从ANN的MAC乘加单元出发，逐步实现了SNN的IF脉冲神经元电路。
>
> 先做了积分器，验证膜电位累积——用加法器和寄存器模拟了生物神经元接收输入后电位逐步上升的过程。
>
> 再加上比较器，实现了完整的IF脉冲神经元——这是SNN最基本的计算单元。
>
> 做完两个电路后，我对比了ANN-MAC和SNN-IF的硬件开销，验证了SNN在功耗上的优势。
>
> 但单纯证明SNN更省电是课堂已知的。所以我在验证完这个必要步骤后，进一步做了定量分析：把SNN在不同准确率下的功耗数据拟合成一条trade-off曲线，回答'用多少准确率换多少功耗'这个问题——这个量化关系是课堂没有的。这就是本课题的最终结论。"
