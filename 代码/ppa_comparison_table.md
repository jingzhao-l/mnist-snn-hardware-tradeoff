# SNN-ANN 面积-延迟-功耗（PPA）综合对比表

> 说明：表中面积为晶体管数量 proxy，延迟基于 2MHz 时钟实测或推算，功耗/能量基于 Cadence 实测数据。

---

## 一、单元级 PPA 对比（MAC vs IF 神经元）

| 指标 | MAC 单元 | IF 神经元 | IF / MAC 比值 | 备注 |
|---|---|---|---|---|
| 晶体管数量（面积 proxy） | 942 | 514 | 0.546 | 基于最终 CDL 自动统计 |
| 关键路径延迟 | 50 ns | 149 ns | 2.98 | @2MHz 满足时序；@10MHz IF 违例 |
| 动态功耗（测试台平均） | 4.876 µW | 2.627 µW | 0.539 | A/B 翻转 / 3 个脉冲事件 |
| 静态功耗 | 0.005827 µW | 0.005951 µW | 1.02 | 输入全 1、CLK=0、CLR=0 |
| 有效单次功耗 | 4.870 µW | 9.611 µW | 1.973 | 动态 - 静态；IF 已按 11/3 折算 |
| 单次操作能量 | 2.435 pJ | 4.805 pJ | 1.973 | µW / MHz = pJ |
| 面积×延迟积（ADP） | 47.1 k transistor·ns | 76.6 k transistor·ns | 1.63 | 越小越好 |
| 能量×延迟积（EDP） | 121.8 pJ·ns | 715.9 pJ·ns | 5.88 | 越小越好 |
| 面积×功耗积（APP） | 4.59 mW·transistor | 4.94 mW·transistor | 1.08 | 综合面积与功耗代价 |

> **观察**：IF 神经元单次操作功耗和能量均约为 MAC 的 2 倍，但晶体管数仅为 MAC 的 55%。MAC 的优势来自其乘法器阵列在输入固定时大部分节点不翻转；IF 的“事件驱动”优势要在系统级稀疏性中才能体现。

## 二、系统级 PPA 对比（MNIST 784→300→10）

| 系统 | 面积（晶体管） | 延迟 @2MHz | 一次推理能耗 | 准确率 | 面积/能耗/延迟备注 |
|---|---|---|---|---|---|
| ANN（串行单 MAC） | 942 | 119.1 ms | 1160.08 mW·cycle | 97.0% | 基线；面积最小，延迟最长 |
| SNN T=50, Vth=0.5 | 159,340 | 25.0 µs | 15.268 mW·cycle | 96.8% | 310 个 IF 神经元；面积 ×169，延迟 ×0.021% |
| SNN T=20, Vth=0.75 | 159,340 | 10.0 µs | 5.651 mW·cycle | 96.0% | 310 个 IF 神经元；延迟 ×0.0084% |
| SNN T=5, Vth=0.5 | 159,340 | 2.5 µs | 0.930 mW·cycle | 92.2% | 最大节能，准确率损失较大 |

> **面积估算**：SNN 隐藏层 300 + 输出层 10 = 310 个 IF 神经元；每个 IF 514 个晶体管，总面积 310 × 514 = 159,340。未计入 synapse/控制逻辑。
> **ANN 能耗**：4.870 µW × 238,200 = 1160.08 mW·cycle。

## 三、ANN 不同并行度下的 PPA 推演

为了与 SNN 做“同面积”或“同延迟”的公平比较，下面假设 ANN 通过增加 MAC 数量来提升并行度。单 MAC 面积为 942 晶体管，功耗 4.870 µW，每次 MAC 运算 1 个时钟周期（500 ns）。

| ANN 并行度（MAC 数） | 面积（晶体管） | 延迟 @2MHz | 能耗 | 与 SNN T=50 对比 |
|---|---|---|---|---|
| 1 | 942 | 119.1 ms | 1160.08 mW·cycle | 延迟是 SNN 的 4764 倍 |
| 10 | 9,420 | 11.91 ms | 1160.08 mW·cycle | 延迟是 SNN 的 476 倍，面积仅 5.9% |
| 100 | 94,200 | 1.191 ms | 1160.08 mW·cycle | 延迟是 SNN 的 47.6 倍，面积 59% |
| 169（与 SNN 同面积） | 159,198 | 705.3 µs | 1160.08 mW·cycle | 延迟是 SNN 的 28.2 倍，面积基本相同 |
| 310（与 SNN 同神经元数） | 292,020 | 384.4 µs | 1160.08 mW·cycle | 延迟是 SNN 的 15.4 倍，面积超 83% |
| 4764（与 SNN 同延迟） | 4,487,688 | 25.0 µs | 1160.08 mW·cycle | 面积是 SNN 的 28 倍 |

> **说明**：上表仅比较 MAC/IF 神经元本身的晶体管面积，未计入 ANN/SNN 的权重存储、控制逻辑与互连面积。
>
> **结论**：即使在面积上让 ANN 使用与 SNN 相近数量的晶体管（169 MAC），其延迟仍高达约 705 µs，是 SNN T=50 的 28 倍以上；若要让 ANN 延迟降到与 SNN 同级，面积需膨胀到 SNN 的 28 倍。这说明 SNN 在事件稀疏场景下具有**面积-延迟联合优势**。

## 四、关键 PPA 指标汇总

| 比较维度 | ANN（串行） | SNN（推荐 T=50, Vth=0.5） | 比值 / 说明 |
|---|---|---|---|
| 面积 | 942 transistors | 159,340 transistors | SNN 面积 ×169 |
| 延迟 | 119.1 ms | 25.0 µs | SNN 延迟 ×0.021% |
| 一次推理能量 | 580,000 pJ | 7,634 pJ | SNN 能量 ×1.32% |
| 准确率 | 97.0% | 96.8% | SNN 下降 0.2% |
| 能耗-延迟积（EDP） | 69,078,000 pJ·ms | 0.191 pJ·ms | SNN 约为 ANN 的 1/361,000,000 |
| 面积-延迟积（ADP） | 112,192 transistor·ms | 3.98 transistor·ms | SNN 约为 ANN 的 1/28,200 |

> **综合判断**：SNN 以约 169 倍的面积换取了约 1/4760 的延迟和约 1/76 的能量，同时只损失 0.2% 准确率。上述面积估算仅包含 MAC/IF 神经元本身，未计入权重存储与控制逻辑。对于延迟敏感、能耗敏感的边缘推理任务，SNN 的综合 PPA 优于串行 ANN。
