# 衍生结论与优化方向（基于本项目数据的再分析）

> 本章严格区分三类结论：
> - **Tier 1（数据直接支持）**：可直接从 CSV、Cadence 仿真或 PPA 推演中读出。
> - **Tier 2（数据强烈暗示）**：需要一步合理推断，但本项目数据提供了强证据。
> - **Tier 3（领域知识推测）**：基于神经形态计算的一般性知识，本项目未直接验证。
>
> 目标：避免把“通用 SNN 优化建议”包装成“从本项目推导出的结论”。

---

## 一、Tier 1：数据直接支持的结论

### 1.1 归一化方法是决定 trade-off 形态的首要因素

数据：
- data_based 在 T=5~50、Vth=0.5~1.5 范围内准确率 92.2%~96.8%，节能 98.7%~99.9%。
- max_norm 只有 Vth=5.0 才能保住准确率，T=5 时准确率跌至 89.6%。

**直接结论**：在本项目使用的 MNIST 784→300→10 网络和 IF 神经元参数下，data_based 归一化显著优于 max_norm。这是数据直接说明的，不是领域假设。

### 1.2 T=50 是 data_based 的“拐点”

数据：
- T=5：92.2% 准确率，99.92% 节能。
- T=10：94.6%。
- T=20：95.4%。
- T=30：96.0%。
- T=50：96.8%。
- T=80：96.4%。
- T=100：96.2%。

**直接结论**：准确率随 T 增加先升后降，T=50 是本项目 data_based 配置下的最高点。T>50 不再提升准确率，反而因脉冲稀疏度下降或累积误差增加而略降。

### 1.3 IF 神经元单次事件功耗约为 MAC 的 2 倍

数据：
- MAC 有效单次功耗：4.870 µW。
- IF 神经元折算后有效功耗：9.611 µW。
- 比值：1.973。

**直接结论**：在本项目的 2MHz、1.8V 测试条件下，IF 神经元每次有效操作的功耗高于 MAC。SNN 的系统级节能不能来自“单次操作更省”，只能来自“操作次数更少”。

### 1.4 SNN 节能来自事件稀疏性

数据：
- ANN 一次推理需要 238,200 次 MAC。
- SNN T=50 总脉冲数约 1,589（1532.8 + 55.9）。
- 操作数比值：238,200 / 1,589 ≈ 150。

**直接结论**：即使 IF 单次功耗是 MAC 的 2 倍，SNN 的操作数少约 150 倍，因此系统级能耗仍然低两个数量级。

### 1.5 IF 神经元延迟是系统时钟瓶颈

数据：
- MAC 关键路径：50 ns。
- IF 关键路径：149 ns。
- 10MHz 周期为 100 ns < 149 ns，2MHz 周期为 500 ns > 149 ns。

**直接结论**：IF 神经元延迟迫使本项目时钟必须降到 2MHz 才能稳定工作。

### 1.6 同面积 ANN 仍无法追上 SNN 的延迟

数据（基于晶体管数推演）：
- SNN 面积：310 × 514 = 159,340 晶体管，延迟 25 µs。
- ANN 同面积（310 MAC）：292,020 晶体管，延迟 384 µs。

**直接结论**：在本项目的“串行 MAC、每个周期一次乘累加”模型下，即使 ANN 使用与 SNN 相近的晶体管数量，其延迟仍是 SNN 的 15 倍以上。

## 二、Tier 2：数据强烈暗示的结论

### 2.1 “零准确率损失”的 SNN 配置可能存在，但节能空间会缩小

数据：
- max_norm T=100, Vth=5.0：准确率 97.0%（与 ANN 相同），节能 94.02%。
- 作为对比，data_based T=50, Vth=0.5：准确率 96.8%，节能 98.68%。

**推断**：SNN 在本任务上可以做到不损失准确率，但代价是更大的 T 和更高的 Vth，导致脉冲数增加、节能优势缩小。本项目尚未扫描 data_based 在大 T 下的表现，因此不能确定 data_based 是否存在“零损失且高节能”的点，但 max_norm 的结果暗示这一方向值得探索。

### 2.2 Vth 的最优区间可能很窄

数据：
- T=50 时：Vth=0.5 准确率 96.8%；Vth=0.75/1.0 为 96.6%；Vth=1.5 为 96.4%。
- T=20 时：Vth=0.75 准确率 96.0%；Vth=1.5 为 95.4%。

**推断**：在本项目网络中，Vth 升高会抑制有效脉冲发放，导致准确率下降；Vth 降低可能放大噪声或导致过早饱和。T=50 时最优 Vth 似乎在 0.5 附近。更精细的扫描（步长 0.1）可能找到更优值，但不能保证一定有显著提升。

### 2.3 4-bit 膜电位可能是准确率瓶颈之一

数据：
- 膜电位位宽 4-bit，最大可表示 15。
- T=50 时，部分神经元在多个时间步内可能累积到接近上限。
- T=50 时准确率达到最高，T>50 反而下降。

**推断**：T>50 准确率下降，可能与 4-bit 膜电位饱和、信息无法继续累积有关。提高膜电位位宽可能允许更大 T 下的有效累积，但这是推测，需要实际验证。

### 2.4 继续增大 T 的收益可能有限

数据：
- T=30→50：准确率提升 0.8%。
- T=50→80：准确率下降 0.4%。
- T=50→100：准确率下降 0.6%。

**推断**：本项目网络的信息容量或膜电位表示精度可能已经饱和，单纯增加时间步长无法持续提升准确率。若要进一步逼近 ANN 准确率，需要改变网络结构或转换方法，而不仅是调 T/Vth。

## 三、Tier 3：基于领域知识的合理推测（未在本项目验证）

以下结论不是从本项目数据中推导出来的，而是神经形态计算领域的常见做法，可作为后续实验方向：

1. **引入 LIF 泄漏项**：可能增强时间局部性，减少早期输入的长期影响。代价是额外电路面积和功耗。
2. **SNN-aware 训练**：直接训练 SNN 或量化感知训练，可能比“ANN 转 SNN”减少离散化损失。
3. **混合 ANN-SNN 架构**：第一层用 ANN、后层用 SNN，可能平衡输入鲁棒性与事件稀疏性。
4. **Temporal / TTFS 编码**：可能用更少脉冲表达更多信息，但对噪声敏感。
5. **DVS 事件相机**：SNN 的真正优势场景可能是处理稀疏事件流，而非传统帧图像。
6. **降低电源电压**：若噪声容限允许，降低 VDD 可近似按 V² 降低功耗，但需重新验证时序。

## 四、不能从当前数据中得出的结论（避免过度推断）

1. **SNN 在所有场景下都比 ANN 节能**：本项目的 ANN 基线是单 MAC 串行；如果 ANN 不计面积成本地堆并行 MAC，SNN 的能耗优势会缩小。
2. **data_based 在所有数据集/网络上都优于 max_norm**：本项目只在 MNIST 784→300→10 上验证。
3. **T=50 是绝对最优**：T=60、70 等中间值未扫描，不能排除更优点的存在。
4. **增加膜电位位宽一定能提升准确率**：这是合理推测，但未实测。
5. **LIF 一定比 IF 好**：需要电路实现和仿真验证。

## 五、后续实验建议（按证据强弱排序）

| 优先级 | 实验 | 预期可验证的问题 |
|---|---|---|
| 高 | 扫描 T=60~150、Vth=0.3~1.0 的 data_based | 是否存在“零准确率损失 + 高节能”配置 |
| 高 | 将膜电位位宽提升到 6/8 bit | 4-bit 饱和是否是 T>50 准确率下降的原因 |
| 中 | 实现并仿真 LIF 泄漏项 | 时间局部性是否影响准确率 |
| 中 | 优化 IF 比较器/加法器延迟 | 能否把时钟提升到 5~10MHz |
| 中 | 用 310 MAC 全并行 ANN 做完整仿真 | 更公平的面积-延迟-能耗基线 |
| 低 | 尝试 SNN-aware 训练 | 从算法层面减少转换损失 |

---

## 六、中立总结

> 本项目数据能够强有力地说明：在 MNIST 784→300→10、单 MAC 串行 ANN 基线、2MHz 2 IF 神经元的条件下，data_based 归一化的 SNN 可以在 T=50、Vth=0.5 处实现“准确率下降 0.2%、节能 98.68%”的优异 trade-off。但这一结论的适用范围受限于本项目具体的网络结构、神经元模型和归一化方法。任何超出本项目参数范围的推广（如“SNN 一定比 ANN 好”“LIF 一定优于 IF”）都属于推测，需要进一步实验验证。
